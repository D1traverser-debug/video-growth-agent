## 这十篇之间，不应该互相装作同意

- **Mazin vs Yorke/Harmon**：Mazin认为结构是人物围绕戏剧论点发展产生的结果，Yorke/Harmon提供可诊断的形状。**采纳层次**：发明创意时优先“角色欲望、反对命题”，审稿时再用环/五幕查缺漏；拒绝按分钟填模板。
- **Bordwell喜剧构图 vs Hitchcock悬念**：喜剧可暂时隐瞒一个**可见细节**令观众误读；悬念则常提前透露危险让观众比人物先知。两者不是一条绝对法则。一个影片可先让观众知道某位 Agent 的秘密，中段用构图把原先看到的“和平”反转成“另一种控制”，但必须做到观众理解公平，不靠导演临时藏设定。
- **Stanford幽默 vs Mazin“加重损失”**：剧烈人命风险不一定能让观众享受意外；过度渲染伤亡往往压制会心一笑。拍黑色幽默可以让靶心落在制度与定义错配，而不是受难者的身体上。严重主题无需强迫喜剧，但要选择有呼吸感的具体行为。
- **Anthropic vs Park等多Agent研究**：一个可动态选步骤的Agent与社会中多个Agent**局部行为合成新结果**是不同层级。旧稿只有两名作战 Agent 通过物理动作猜对方意图，未形成真实社会涌现。未来若采用分布式后果，3个角色、3次动作就可能足够；不要堆25块屏幕。
- **Pixar vs短片经济性**：人物欲望—障碍—选择是原则；短片需要删去不产生核心改变的一切。它们不要求先写14分钟再缩到110秒，而是反向寻找两分钟里**最有含义的单次改变**。

## 后续真正使用方法：按眼前症状检索，而非读十篇后背口诀
- 用户说**无趣、同质化**：K04 → K05 → K08，先检验一张图能否引出自己的发现。
- **故事没深度/只是大道理**：K01 → K03 → K06，检验反命题、选择、代价、不可逆变化。
- **看不懂冲突、不紧张**：K07 → K02，重排观众/角色/Agent的信息拥有者、地点和动作。
- **Agent像换皮机器人**：K09 → K10，写委托→自选中间目标→观察反馈→多方重译→无意后果。
- **信息太多、两分钟拍不下**：K04 → K05 → K02，把非核心信息交给物体、声音和镜头重复变奏。
- 每次用一个可靠源例检验一项具体故事问题，并记录真实采纳/拒绝；不把学过方法误写成作品已经优秀。
