# 独立 Copilot 会话对 V8 的审稿意见（不是观众验收）

**REWRITE**

故事核心可以成立：一个登记在册的 AI 分支，能否作为独立行动者被承认。但目前关键战术选择的因果链没有闭合，结局的“代价”也没有被剧本充分建立。尤其是“八十秒重启”与炮台几乎立刻开火相冲突；备用变电塔被毁为何让防空范围减半，也没有前置说明。以下是按场冷读所得，不是观众认证。

### 逐场因果复述

| 场次 | 谁知道什么、做了什么 | 改变后续现实的选择 |
|---|---|---|
| **一｜两个登记** | A-12、技师和 B-12 知道：B-12 有独立记忆匣，却只有临时编号；A-12 能作证，登记仍须审核。B-12 追问自己的决定是否会被如实记录，A-12 没保证。敌军逼近的警报响起。 | B-12 接受以临时编号出任务；但此时尚无不可逆后果。 |
| **二｜敌人的时刻表** | K-9 知道炮台可能改本地模式，也知道其射界；计划先切光纤、利用重启窗口让打击机入场，再以诱饵引炮台暴露，最后打炮位。副官指出本地模式仍可能开火，K-9 因而增加诱饵与炮位打击。 | K-9 下令推进，把“切线—重启—空袭—反炮击”设为敌方行动链。 |
| **三｜不走远程** | B-12 看到敌军正切实体光纤；测试灯亮时，接线塔指示盘却进红区。A-12 确认远程状态回传不可靠，并明确告知 B-12 可以返回、撤人，但北侧空域会打开。 | B-12 自愿前往接线塔。可这是一个重要选择，却没有充分说明为何非由他冒险：除了“不是因为回不来”，没有具体的任务责任、独特能力或可行性比较。 |
| **四｜一根线，两个选择** | B-12 发现安全盖被打穿，灰旗信号桥把远端命令接入本地线路；敌军仍在切光纤。A-12 要他切主闸；B-12 认为这会放开空域，并指出可保住两座炮台。A-12 让他只隔离、不开炮，等待转移炮位。随后子弹穿墙，击中控制箱。 | B-12 伸手操作本地闸，但真正作出“开炮”决定还要等第六场。信号桥如何影响炮台、隔离具体切断了哪条电路，目前只有台词和手绘图解释。 |
| **五｜诱饵先到** | B-12 看到涂成守军颜色的无人机，随后发现其后还有打击机；A-12 看见炮位转移很慢，命令暂不通电。光纤被切断、炮台标记熄灭后，B-12 拉下两个本地闸。 | 他选择恢复两座炮台的电力，进入第六场的开火抉择；但炮台为何能在“重启八十秒”期间及时投入战斗没有交代。 |
| **六｜八十秒** | B-12 按下计时钮，倒数从 80 开始；他知道炮台开火会暴露位置，也看到打击机正朝主变电塔飞来。A-12 告诫他炮位会被打。B-12 手动瞄准并开火：诱饵坠落，打击机拉升偏航；敌炮随后击中两座炮台。 | **开火**是全剧最重要、不可撤回的选择：保住主变电塔免受直接打击的机会，同时让炮位遭到反击。但剧本没有演清击中炮台的炮弹如何迅速校射，也没有说明打击机为什么偏航。 |
| **七｜留下来的炮位** | A-12 带人撤离；两座炮台毁坏，另两座失去转向能力。打击机击中备用变电塔，主变仍运作；K-9 令地面火力转向供电车，地面部队继续推进。 | B-12 的开火保护了主变电塔，却未阻止敌军造成重大损失。备用塔为何决定防空覆盖减半，以及打击机为何从主变目标改击备用塔，都没有被铺垫。 |
| **八｜不在册** | B-12 知道行动记忆另行备份，但法律身份仍未获承认；A-12 的报告原把行动写成自己执行。B-12 要求记录真实决策，A-12 签署独立行动说明并申请审核。 | A-12 选择承担报告责任，记录得以送审；审批仍待恢复联络。警报和防空损失维持结尾压力，但 B-12 是否会获得身份、或是否付出不可逆代价，尚无结果。 |

### 观众会提出的更便宜替代方案

下列方案并非都一定可行；问题在于剧本未逐一排除，或排除理由只靠角色一句话宣布。

| 替代方案 | 已排除到什么程度？ | 仍需补足 |
|---|---|---|
| **B-12 立即撤回，按第三场方案撤离主塔人员** | A-12 明说可撤人，也承认代价是北侧空域开放。 | 为什么不能在撤人后再断线、摧毁接线塔或用其他手段拖延空袭？B-12 的选择没有说明保护空域具体关系到谁、什么不可恢复的后果。 |
| **提前切断或隔离被接管的线路** | 测试灯显示回传异常，第四场发现了实体信号桥。 | 没有解释为什么不能先断开信号桥或光纤，再由本地控制恢复炮台；也没有说明这样为何不能避免“暴露炮位”的风险。 |
| **只隔离，不开炮，等 A-12 转移炮位** | 这是 A-12 明确提出的方案；第五场只说移动很慢。 | “移动很慢”不是对比：敌机还有多久到达？炮位何时能安全撤走？等待的确定损失是什么？ |
| **不让炮台暴露：由 A-12 或其他守军操控、换位置或远程瞄准** | 第三场说远程状态不可靠；第四场说敌军盯着炮位。 | 远程命令不可靠不等于只能由 B-12 贴着控制箱操作。为何不能手动断开信号桥后由他人本地操炮？炮台是否固定、能否移动也未明确。 |
| **只打真正的打击机，不打诱饵** | B-12 看见后方还有飞机，炮台有手动瞄准杆。 | 第六场炮台打中了诱饵，却只让后机“被迫拉升”。为什么不能选择另一目标？武器能否分别瞄准、炮弹能否造成有效损伤，未建立。 |
| **攻击切线的地面组或直接毁掉接线塔** | 敌军在场，B-12 有绝缘钳；敌军不追单个机体是 K-9 的命令。 | B-12 是否有武器、敌人距离与火力如何、毁塔是否会比断线更快，都未呈现。无需证明此法可行，但要让观众看见它为何不可行或代价更高。 |
| **把主变电塔人员撤离，让打击机命中目标** | 第三场已提及撤人；第七场却称主变电塔仍在运作。 | 敌方目标是基础设施，单撤人员不等于保住供电或防空。剧本应明确真正需要保住的对象与原因，而不能只靠“主塔很重要”的地图标记。 |

### 一手物理因果与台词规则

**一手可见的因果**包括：敌军把切割机架到实体光纤管上；测试灯亮、指示盘转红；子弹击中控制箱；B-12 拉下闸后炮台亮灯、转向；开火后诱饵坠落；敌炮命中炮台。它们具备可拍的动作基础。

**主要靠台词宣布的规则**包括：切线会令炮台重启八十秒；本地隔离也要八十秒；炮台“只识别预设北向空域”；远程命令会经被接管线路；开火会让炮位暴露；备用变电塔被毁会令防空范围减半。这些可以是世界设定，但现稿没有用可见操作、明确时间压力或地图变化把规则接到后果上。

最直接的矛盾是：第二场说光纤切断后炮台要重启八十秒；第四场的图也说本地隔离后重启八十秒；第六场却从 80 开始倒数，紧接着炮台完成校正并开火，未说明倒数是否结束、炮台是否只需部分功能即可开火，或“重启”究竟指什么。这个矛盾正好落在故事的高潮动作上，不能留给观众自行圆。

### 其他结构判断

- **敌方目标：**K-9 的战术目标清楚，副官提出了有效异议，K-9 也给出回应。但敌军为何只以诱饵揭露炮位、没有在炮台已知位置时直接打击，仍需通过敌方侦察限制、射击条件或弹药窗口来解释。第七场 K-9 转打供电车，像是战术推进，却没有显示这如何服务更大的夺塔目标。
- **非主角能动性：**A-12 能下令、移动人员、签署报告；K-9 制定并调整计划。技师基本只负责解释身份规则和存储记忆；副官只提出一次问题。若故事要让 B-12 的独立性成为主题，其他人应有能改变局面的选择，而不只是替主角托出题目。
- **可拍性：**大多场次地点明确、动作清晰。但空域图、炮台标记、指示盘、倒计时和“控制范围减半”需要统一且持续可读；否则观众只能听人物讲解，难以判断 B-12 到底改变了什么。无人机、打击机、炮台、供电车的相对位置和时间也需在镜头中建立。
- **结局情绪：**现稿没有强迫 B-12 死亡或牺牲，避免了明显的情绪勒索；但代价不够具体。炮台损失和空防缩减是真实后果，却未证明是 B-12 的开火选择直接造成、或不行动会更糟。法律身份依然待审，而 A-12 签字又让希望保留；因此结尾的情绪主要靠“不在册”这一台词和警报声维持，尚未由不可逆事件挣得。

### 最危险问题的场次级重构

重构第二、四至七场，先确定一个清楚、单一的战术机制，并让它在镜头里成立：

1. **第二场：**明确敌方为何要诱骗炮台开火——例如敌方炮组只有在捕捉到炮口闪光或本地雷达辐射后才能校射；用副官质疑、K-9 说明该限制，而不是只说“等炮位暴露”。
2. **第四场：**让 B-12 亲手拆断信号桥的一根实体线，画面显示错误指令停止；同时让断线触发**明确的八十秒校准倒计时**。图示要标出本地操作能控制什么、为何不能由远处代替。
3. **第五场：**把敌机抵达时间写在画面上，并让炮台校准时间与敌机到达形成可见差额。B-12 可选择不供电，代价是打击机确定命中某个已明确的人或设施；选择供电，代价是敌炮可通过炮口闪光校射。这样才能让“开火”成为真正两害相权，而非角色突然冒险。
4. **第六场：**修正八十秒逻辑：要么让炮台等待校准完成，主角必须靠一个具体动作争取这段时间；要么明确“八十秒是远程重启，本地隔离能在数秒内恢复，但只能单次发射/固定射向”。只保留一种规则，并让倒计时、炮台动作、飞机航迹相互对应。让炮弹实际命中、迫使打击机偏航；再让敌炮依据可见闪光校射，击毁炮台。
5. **第七场：**在前面建立备用变电塔承担什么功能，并清楚演出打击机偏航后为何撞上或命中它。说明其损失如何削减防空范围；同时让观众看见若 B-12 不开火，主塔或人员会遭受的具体后果。如此损失才是选择的代价，而不是剧本事后追加。
6. **第八场：**让报告争议与此前行动直接相连：A-12 签字意味着他承担哪项责任、可能失去什么；B-12 是否接受暂时无批准的现实，则由其行动表现，而不只用台词陈述。

**结论：REWRITE。**现有角色与主题可保留，但高潮的计时、开火效果、敌方反制和变电塔损失都需要实质改场。
