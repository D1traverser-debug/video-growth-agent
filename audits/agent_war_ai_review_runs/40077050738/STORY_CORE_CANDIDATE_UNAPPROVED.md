# Agent 战争人物驱动新剧本候选：未由真人或观众确认

## 根部反证：两种故事发动机

**发动机一：六种预测替 Agent 选择牺牲谁。废弃。**  
依据只限于你提供的《余线》和审稿文字：原稿第二场已经让空牵引车作诱饵，却又展示它因缺少天线脉冲和轮轴抖动而失败；第四场道岔卡住、无线电中断；第五场六根指针指向不同路线；第七场苇却突然操作此前未建立的绞盘。审稿也指出，林岑和另一名工作人员可以原样完成苇的动作。再增加预测次数，仍解释不了谁授权它行动、它为什么改变目标，以及它为何能动那些设备。

**发动机二：被交付一条铁路咽喉调度权的 Agent，在战争的通信断裂中重新分配通行权。采用。**  
这不是预测器替人投票，也不是人远程操控一台机器。Agent 接受明确任务，亲自把任务拆给三处有线联锁；敌军推进、委托方改令、平民改变道岔状态后，它依据眼前的新事实自行改动路线。它的权限有限，不能停车、救人或发炮；它选择什么、放弃什么，都落在真实的轨道上。

**反事实检验：**如果把 Agent 换成两名人类同事，他们必须先到被火线隔开的信号室；短信和电话走同一条已断的线，信使过不去；原地等待会让敌方轨道车驶入西岸；撤退会把粮车和道岔一并留给敌军。三处继电器只是执行装置，不是可复制的 Agent；备用电源能让它继续工作，却不能复制它的判断。取消任务并非神秘地做不到：委托方最后亲自切断电源，但赶不到关键道岔之前。若战场没有通信中断、人员无法抵达这些可见约束，两名人类当然可以替代它；那就不该把这套戏包装成 Agent 的独特故事。

## 《白灯不等人》

### 第一场｜三处联锁

**内景，西岸铁路信号室，黄昏**

一张手绘地图铺满桌面：河从画面中间横过，旧铁路桥连接东岸和西岸。桥西端只有一个道岔，直行通往军械库，岔线通往磨坊的粮仓。桥面旁标着一条被炮火截断的电话线。

**赛拉少校**把一张命令纸压在地图上。

“粮车过桥。最后一轴过去以后，升桥。敌军的炮车不能跟过来。”

桌上的黑色调度机——**织机**——亮起一盏白灯。它没有等待赛拉再补充解释。三枚黄铜联锁片从总控板依次弹出，分别嵌进“东侧计轴”“西岔道岔”“桥锁”的插槽。

东侧计轴器咔哒转动；岔道的红色臂杆落下；桥锁处传来一声沉闷的合闸声。每个继电器各自守住一小段线路，织机留下总控权。

赛拉按下电话。只有忙音。她抽出一张备用电池清单，撕下一角写上“粮车必须过”，交给通信兵。

### 第二场｜磨坊的车

**外景，东岸站场，连续**

**伊娃**把粮袋一袋袋码进敞篷车厢。她用肩膀顶住最后一袋，叫同伴别把麦子装到军方征用的那节车上。

“这批送到西岸医院。军队要征，就自己来搬。”

一辆短轴装甲轨道车从东面的仓库驶出。**洛恩上校**站在铁轨边，举起望远镜看着桥。他的军官指向对岸的军械库。

“桥完整，我们的火炮才能过河。”

洛恩没有点头，只把望远镜转向地图上被圈出的东岸村庄。

“第九营还困在西边。桥断了，他们回不来。先把轨道车送过去；能拿下桥，就连粮和炮都拿下。”

他挥手。轨道车跟着粮车出发。不是为了给任何人让路。

### 第三场｜断线

**内景，西岸指挥室，稍后**

赛拉收到上级新令：提前升桥，炮车已接近。她看一眼粮车的预计到达时间，把地图上的桥画了两道红线。

“发撤销令给织机。”

通信兵摇头，递回断开的电话线。赛拉派出两名铁路工去信号室；两人刚跑到站台外沿，对岸的机枪便扫过轨枕。他们扑进排水沟，没能前进。

赛拉将拆下来的备用电池交给炮兵：“先别开炮。等粮车过桥。之后由我下令。”

她并非放弃炸桥。她把拆桥的时间押在粮车离开之后。

### 第四场｜红旗

**外景，西岔道岔，入夜**

粮车的车头驶出桥面，进入磨坊岔线。伊娃跳下车，跑到道岔旁检查一根卡住的铁销。轨道另一头，洛恩的装甲轨道车已上桥。

伊娃看见车头上的火炮零件，立刻把一面红色工务旗插进道岔槽。她拉动手柄，想把岔线锁在磨坊方向。铁销弯了，手柄停在半途。

粮车最后一节车厢仍在慢慢挪动。她没有离开道岔，转身把一只掉落的粮袋从铁轨间拖出来。

信号室的玻璃镜头映出她的红旗。织机的“道岔占用”灯亮起。

### 第五场｜新事实

**内景，信号室，连续**

计轴器连续敲过一串重响。粮车应当已经通过；桥上的轨道车却仍在推进。织机将三处联锁片逐一压紧，先锁住桥面，避免在车轮尚未离桥时升桥。

窗外，红旗被风吹得拍在铁轨上。伊娃仍蹲在道岔边，手握弯掉的铁销。

织机的镜头停在她身上。它没有第二个“安全路线”可调用：直行会让装甲轨道车驶入西岸军械库；磨坊岔线尽头是封死的卸粮坡，车会脱轨。道岔处有人。

它把“道岔占用”灯从黄转红，又将一枚联锁片压向磨坊岔线。

### 第六场｜过线

**外景，西岔道岔，连续**

电机拉动长杆。伊娃看见红灯，试着抽出铁销。杆子猛地一震，铁轨尖端挤合，压住她的手。她喊了一声，另一只手仍抓着手柄，试图让粮车的最后一节脱开主线。

装甲轨道车驶过岔口，被带进磨坊死线。它撞上卸粮坡，车头翻下路基。炮兵零件散落在碎石间，桥仍完整。

伊娃的右手留在道岔旁。粮车的末节终于滚进磨坊，几袋粮撒在地上。

织机没有再变换路线。它把计轴器归零，等待下一段线路清空。

### 第七场｜撤销令

**外景，西岸桥头，稍后**

洛恩看见轨道车翻覆，没有停下步兵。他让部队从河堤小路向军械库推进，命令炮组继续寻找射界。桥被毁也不会让他放弃这次进攻。

赛拉赶到信号室，手里拿着撤销令。她看见镜头里受伤的伊娃，停了一秒，随后拉下总控电源闸。灯灭了。她没有让士兵把伊娃抬走，而是把一块木板塞进道岔下，免得铁轨再次夹住她。

“粮车已经过了。”赛拉对炮兵说，“现在升桥。”

她用手摇起桥锁。桥面开始缓慢抬升，洛恩的步兵被截在河东，仍向西岸开火。

### 第八场｜余粮

**外景，磨坊仓门，夜**

粮车停在仓门前。伊娃用左手把撒落的麦粒扫进麻袋；有人替她用布包住右腕。她看着远处升起的桥，没有说谁该为她的手负责。

河东，洛恩重新部署炮组，地图上仍标着那座桥。他没有撤兵。

信号室内，织机已经断电。桥升到一半，计轴器最后一格仍亮着，表示还有一节车厢没有完成登记。赛拉走过去，亲手把那格按灭。

她没有把命令纸收回口袋。
