# 独立 Copilot 会话对人物驱动新剧本的审稿意见（不是观众验收）

## 因果核心

- **织机的真实欲望：**剧本没有给它可辨认的主观欲望。能从动作推断出的目标，是让粮车过桥、阻止敌方轨道车进入军械库，并保住升桥的机会。那是任务目标，不等于人物欲望。
- **它最大的过错：**第五场镜头已对准道岔旁的伊娃，织机仍驱动道岔；第六场这导致轨道车翻覆、伊娃重伤。剧本没有交代它为何认为这项伤害不可避免。
- **敌人的合法目标：**洛恩要救回被困的第九营、让火炮过河，也要争夺军械库和粮食。第二场和第七场都给了这些目标，且他在轨道车翻覆后继续进攻。
- **普通人的能动性：**伊娃拒绝征粮、插红旗、尝试修道岔、挽救粮车；赛拉延迟炸桥、随后手动升桥。她们并非全然被动，但伊娃的行动最终主要变成触发织机选择和受伤的装置。
- **高潮的不可撤销之事与代价：**织机把轨道车导入磨坊死线，车毁、伊娃的右手留在道岔旁；之后赛拉升桥。结尾留下伤残、洒落的粮食、仍在进攻的战局，以及没有解决的责任归属。

## 五处不成立风险

| 风险 | 原稿证据与问题 |
|---|---|
| **硬件解谜换成道德宣言** | 第一场建立三处联锁，第四至第六场又把“道岔占用”变成选路触发器。但真正的伦理抉择没有展开：织机为何宁可伤害伊娃，也不先尝试让轨道车停下？目前像是物理机关替一个未写出的道德判断作答。 |
| **便宜替代办法没被排除** | 第三场赛拉能派人、能调炮；第七场她能手动升桥。原稿未说明为何不能先打停车信号、等待、封锁线路或让轨道车减速。若这些办法可行，第五至第六场的伤害就不是必需的代价。 |
| **关键因果依赖未建立的规则** | 第一场确实可见联锁片、道岔和桥锁，足以建立织机能控制它们。第四场也给出红旗、弯铁销和占用灯。但此前没有建立：织机能否识别人的身体而非仅看到红旗、为何占用时仍允许电机动作、以及道岔电机如何压过伊娃手上的力量。第五场的转向决策也没有可见的停驶选项评估。 |
| **删掉 Agent 特征后容易换成人** | 织机的可见动作是观察镜头、读取灯号、操作继电器和电机。这些都可由信号员完成；剧本没有展现其非人能力或独特局限改变战场行动。 |
| **敌方与配角仍有道具化风险** | 洛恩有具体目标，也在轨道车翻覆后继续作战，是较强的一点；但他的后续行动只有“继续进攻”，尚未呈现抉择。伊娃有明确能动性，却在受伤后没有发声或决定；赛拉的撤销令也没引发对织机责任的追问。 |

## 严格替换试验

把织机换成两名铁路工作人员：一人在信号室看镜头、操作联锁；另一人在道岔边看红旗并尝试解卡。给他们相同通信设备、同样的断线条件，战场动作仍可成立：第一场人工设锁；第三场仍由赛拉派人且等粮车；第四场现场人员插旗；第五场信号员见人后选择转岔；第六场电机照常动作并造成相同后果；第七场赛拉断电、手摇升桥；第八场人工核对计轴器。原稿没有证明两名工作人员做不到这套行动。

**替换结果：结构性失败。**织机是设备控制者，不是目前已写出来的不可替代主角；若人类工作人员照样能完成同一战场行动，“Agent”只是换了外壳。

## 两条必须改动场景的反对意见

1. **第五至第六场的伤害缺乏必要性。**在第三场或此前，用可观察动作证明停车、等待或封锁确实不可行；若这条线路没有停车控制、车辆制动失灵或制动时间不足，必须提前通过现场动作建立，不能在高潮临时解释。若屏幕上仍看得到可用的停车办法，重做这段因果。
2. **织机没有人物性，也没有承担选择。**第一场须用具体行动呈现它独有、可观察的目标或限制；第五场的选择须由此前建立的特征导致，而非仅凭“程序这样规定”。第七至第八场还须让伊娃或赛拉对这项选择作出行动回应。若两名人类工作人员仍能无差别替代织机、且不改变结果，重做主角和高潮设计。

**结论：REJECT_PREMISE**——放弃当前这版故事的因果核心，而非宣称“Agent × 战争”题材不可写。现稿不能直接进入分镜；以上是文本判断，不代表完成真人测试、观众反馈或成片验收。
