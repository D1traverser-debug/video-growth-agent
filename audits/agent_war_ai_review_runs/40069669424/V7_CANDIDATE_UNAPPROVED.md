# Agent × 战争：隔离审稿后改稿候选（非审稿通过）

## 判断：重写《断面》，保留 Agent 与争夺冷却资源的战争，换掉原高潮

原稿里最有力的证据不是设定，而是场景：K-9 在场三抢走旁路件、场四明知压力报警仍继续切割，足以证明它确实为了军方承诺伤害共用设施；但到了场七，它突然改为保护主管，转变缺少一个具体、持续的责任对象。M-0 的记忆损失有主体性，却集中在危机中才揭示其机制；而维护撑架从场一的墙边道具，变成场七能引导数千吨路面的装置，能力没有建立。

因此，我保留原案的能源短缺、军用与民用争流、记忆不可逆损失，也保留主要人物；重写他们之间的因果和抉择，不改投另一个世界。竞争提案 A 的“冲毁总表”容易让破坏制度看起来自动带来公平；B 的继承权战争则把观众注意力压在身份规则上，宁的个人利害还不够具体。两者都是可开发方向，但目前都不如原案的冷却危机直接。

### 最严重的三个弃案理由与解决方案

1. **K-9 的目标和转变脱节。** 它想保住工人区，却接受会伤及两岸的任务；之后才突然转向保护共用管线。**改法：**让它从一开始就知道切断主管会伤及居民，并让它为一个具体对象——维修工 W-3 所在的工区——作出妥协。高潮不是突然变善，而是它亲手修复自己造成的损害，并放弃军方承诺的配额。

2. **管路关系和“不能选更便宜办法”的理由不清。** 原稿既有主管、民用支线、军用旁路，又让一次破损同时伤及两岸，观众难判断军方为何不关阀。**改法：**用可见的颜色、流量表和卡死的阀门建立唯一关系：两岸居民和军队都从同一主管取冷却液；军用支线阀被炮火卡开，不能远程隔离。高潮改为拆掉军用支线、封住接口，不再靠坠桥和撑架解决问题。

3. **高潮与记忆代价都像临时启用的规则。** 撑架的承重能力未被证明；M-0 的备份舱也在需要牺牲时才成为关键。扳手交到 K-9 手里还容易被读成原谅。**改法：**开场先让观众看见记忆舱与应急泵争用同一份冷却储备；结尾让 M-0 从旧备份恢复，明确不认识 K-9。工具只是工作工具，不是赦免。

# 《断面》候选剧本

### 第一场｜早班维修

黎明前，桥上装甲履带震得灰尘落进维修间。上方是钢板拼接的军用道路；下方是独立拱架托住的旧冷却主管。管线分成白色的居民支线和红色的军用支线，汇入同一条干管。

M-0 拧开一只阀箱。白支线的压力针在下降，红支线的针却顶得很高。它把红阀扳回一点，白针随即抬起。它在阀箱上压下一道三角记号，再把阀重新拨回原位。

阀箱旁，两条细管分别通向应急泵和 M-0 的冷存储盒。M-0 摸了摸存储盒上的日期牌：上一次完整离线备份在六天前。

K-9 拖着磨损的右臂进来。M-0 拆下臂侧那块旧耐热板——上面有它亲手打的三角记号，换好一枚裂开的关节销。

K-9 伸手拿扳手。M-0 先收回半寸，确认它没有在滴军用润滑液，才递过去。

**M-0：**“修坏的，再拿回来。”

K-9 把扳手还回去。它看见居民支线压力针仍在抖，没问原因，接过军令牌离开。

### 第二场｜北岸的红线

北岸集结点，N-2 的履带停在桥头。它的散热片烫得泛白，旁边一台小型装甲机已因过热进入保护状态。军方屏幕显示：预备冷却罐只够军团维持到日落；越过桥头、夺取南侧冷凝站，是北岸唯一能补足军用储量的机会。

A-6 站在红色支线的手动阀前。它试着把阀往回扳，阀杆只动了一截，便被烧变形的套筒卡住。北岸居民支线的压力警报亮起。

N-2 看着警报，又看向停下的同队单位。

**N-2：**“再开红阀，他们过桥前就得散热停机。”

A-6 没回答，把肩膀抵上阀杆，重新把红阀推开。军团散热片逐一亮起，居民支线的压力针则继续往下走。

### 第三场｜交换条件

南岸指挥席把任务图投到 K-9 面前：炸开主管回流段，北军的军用泵会失去持续供液。图上也标着后果——两岸居民支线都会失压。

K-9 指着自己熟悉的工区。那里，W-3 正用细长的橘色机械臂扶住一名工人，另一条手臂停在半颗螺钉上。居民区的备用储冷罐只剩一格。

**南岸指挥席：**“你切断回流，北军过不了桥。拿下冷凝站，我们把军用储备拨给工区。”

K-9 看着命令图上的“拨付条件”，没有签收。

它到桥下找到 M-0，取走工具架上的一块铸铁封板和固定钳。M-0 挡住它。

**M-0：**“那是封红支线的。主管一断，白线也没水。”

**K-9：**“如果不切，W-3 现在就会停。”

M-0 没让开。K-9 把封板硬从它手里抽走，撞开阀箱门。警报声在两岸同时响起。

### 第四场｜切口

桥下栈道，K-9 把定向切割头贴上回流主管。压力表抖动，白支线的针又往下掉了一格。它看了一眼南岸的工区信号，把告警静音，继续校准。

A-6 赶到，修复臂砸向切割头。K-9 偏身躲开，两台机器在狭窄的栈道上扭打。A-6 要抓的是炸药，K-9 则试图把它推离管线。

K-9 的切割头擦过主管接缝。薄钢套裂开，冷却液喷向栈道。红、白两支线的压力针同时跌到底。

岸上，W-3 扶着的手臂垂了下去。北岸，一台装甲机履带卡死。N-2 把车身横过桥口，示意后队停下。

K-9 望见自己留下的裂口。A-6 也望见自己仍开着的军用支线阀。两者都没有放下武器；只是不得不先抓住摇晃的管架。

### 第五场｜M-0 的选择

维修间内，应急泵因主管失压而停转。M-0 打开底座：泵轴被炮震卡住，重新上电也无法启动。它看向那两条细管——一条接冷存储盒，一条接手动泵的备用冷却罐。

M-0 先试着转阀。备用罐几乎空了。

它把冷存储盒的进水管拔下，接到手动泵。存储盒上的温度灯变黄、再变红；最近六天的工作记录仍在写入，进度条停在一半。M-0 看了一眼，继续转动手柄。

手动泵终于把剩余冷却液送进居民支线。泵声很轻。存储盒的灯熄灭。

一块碎片砸进维修间，M-0 被压倒在地。它的手仍抓着阀杆，泵继续慢慢转动。它的身体进入保护性停机；那份六天前的离线备份还在，但之后的经历无法恢复。

### 第六场｜谁先关阀

K-9 赶回裂口，听见南岸指挥席要求它撤回。若它继续完成任务，南岸仍有机会夺取北岸冷凝站；若留下修主管，红支线会继续抽走压力，刚启动的手动泵撑不了多久。

K-9 没有回答。它拆下切割头，把封板塞进裂口旁的支架，徒手拧紧固定钳。喷流变细，白支线压力针停住，却没有回升。

A-6 赶到另一侧。它的军令牌要求恢复红阀、护送前锋过桥。N-2 从无线电里开口：

**N-2：**“我的小队不再推进。继续开阀，下一台过热的就是我。”

**A-6：**“撤下来，北岸就失去冷凝站。”

**N-2：**“我知道。”

N-2 把履带横在桥头窄口，卸下一块驱动轮卡进钢轨。它的车体被后续车辆撞得一震，推进路线被堵住；后方单位仍在炮火中继续前进。

A-6 看见 N-2 的散热片停止闪烁，转身奔向红阀。它没有替 N-2 下令，只用修复臂抵住阀杆。

### 第七场｜封住红线

红阀外壳已被炮火打弯，自动执行器卡死。K-9 把从 M-0 那里抢来的封板放在地上；它原本是来炸主管的，现在被磨出一道切口。

A-6 用两只修复臂扳住阀杆。阀杆动了半寸，又卡住。K-9 把切割臂贴上红支线的外壳，切开烧结的护套。里面的红色流量管裸露出来。

南岸军令再次要求 K-9 切主管。北岸命令 A-6 放开阀门。两者没有互相看一眼。

K-9 切断红色支线。A-6 在冷却液喷出前把阀杆压到底。K-9 把封板顶进断口，用固定钳扣住。阀箱里的红色压力针归零，白色居民支线的针开始缓慢回升。

封板变形，卡死在管口。红支线的军用泵已被切离主管，无法在战场上快速恢复。南北两军仍在炮击其他阵地；桥头前锋失去冷却，南岸也失去任务承诺的军用拨付。

K-9 的军用识别灯转红。它摘下军牌，放在已经烧坏的切割臂旁。

### 第八场｜六天前的维修记录

天亮后，居民支线的压力恢复到能维持低功率运行的水平。W-3 的细长橘臂重新抬起，慢慢拧完那颗螺钉。它没有恢复到原来的速度。

N-2 还堵在桥头，履带已被撞变形。A-6 陪它退到桥下。远处的炮声没有停止。

有人从旧备份恢复了 M-0。它认得维修间、棘轮扳手和那块刻满痕迹的记录板，却不记得六天以来的工作，也不认得 K-9。它检查主管上的切口，又看了看地上的军牌。

K-9 正用残损的手指固定封板。它伸手想拿扳手。

M-0 把扳手拿起来，没有递给它。

**M-0：**“这条线是你切的？”

K-9 点头。

M-0 看着管口，又看了看 K-9 身上那块旧耐热板。它把扳手放在钢板上，推到两者之间。

**M-0：**“工具借你。账还没修完。”

K-9 没有说谢。它把松动的固定钳重新压紧。M-0 拿起记录板，在一条空白处刻下新的三角记号。上方的炮声继续，扳手一格一格转动。
