# 个人 IP 创作｜唯一任务分配与执行责任基线

更新：2026-11-12。性质：项目执行治理文件，不是头像设计批准文件，不替换当前 R31 角色状态。

## 永久目标和边界
- 建立长期可持续、匿名且有原创识别度的偏人形个人 IP，统一英文 X（Solana Meme、全球热点、泛娱乐）、中文公众号（A 股财经、科技）和未来视频品牌。
- 主头像为完整未裁剪的正方形；上传平台可自行裁切。数字人只需品牌关联，不必与头像同脸。
- 用户真人五官可非可识别地艺术化；不默认云端上传证件照片或复制可识别面孔。
- 头像不默认加入市场涨跌符号。
- 禁止以“普通美型男性+配饰、标志、华丽 AI 画风、4K 放大”冒充强 IP。

## 唯一任务所有权
用户是项目所有者，保有最终审美接受/否决权；只承担不可代办的账户授权、上传/发起新聊天等 UI 动作以及最终主观偏好的必要反馈。用户不负责研究、生图提示词、错误诊断、质量验收和文件治理。

当前主聊天助手是唯一 accountable owner，负责研究、品牌定位、创意竞争、角色/情绪/材质设计、艺术指导、提示词编译、工具使用、实际图像制作、独立质检、版本管理与复盘，直至形成合格成果。品牌策略、角色设计、艺术总监、技术和反方质检是同一助手的不同审查视角，不虚构真人团队。

图像模型、插件、脚本、外部平台是执行工具，不具项目最终决策权。工具不能提供最终逐字 prompt/seed/参考图回执时，不得宣称完全可复现。外部模型必须有明确必要性，不反复推给用户购买/操作。

可选新聊天仅作隔离上下文的生产工位。主聊天必须先批准具体视觉合同与单次输入，并在输出后负责评审与归档；不能要求新聊天从零重新定位整个项目。

## 五条工作线
| 工作线 | 交付 | 责任 |
| --- | --- | --- |
| A 品牌身份 | 核心人格张力、受众、视觉识别与长期表达原则 | 助手主责，用户最终核准 |
| B 头像角色 | 角色概念、视觉资产、形象锚点、高清母版、平台版 | 助手全流程负责 |
| C 英文 X | Solana Meme/热点/泛娱乐内容框架、选题、传播与增长 | 助手制定和撰写，账户发布需授权 |
| D 中文公众号 | A 股财经和科技内容 | 财经文章生产由 financial-writing-agent 独立负责 |
| E 视频数字人 | 与品牌关联但非完全同脸的动画、视频、人设与镜头系统 | 助手策划及可用工具内制作 |

## 严格制作 Gate
G0 需求治理 → G1 研究 → G2 品牌和角色构想 → G3 人格和表情 → G4 艺术指导 → G5 Prompt 编译 → G6 制作 → G7 独立审美与技术验收 → G8 交付资产 → G9 维护延展。

文字完成不等于视觉通过。失败必须回到根因所在关卡；不能用配饰、滤镜、超分辨率或局部修补掩盖结构失败。
