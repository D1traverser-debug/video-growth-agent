# Editorial packaging: news × video × natural language

Scope: projects/ai-self-media-commercialization, Video-owned. CAOS governs the chat's diagnosis and evidence standards externally and remains STRICTLY READ-ONLY. This is not a copied parent controller or a new release authority.

## End-to-end meaning path

1. Recover owner goal and corrections; distinguish verified facts, attributed reports, unverified allegations, fictional/staged visuals, interpretation, and publication requirements.
2. Investigate current public sources and inspect exact media bytes, rights and digest. An HTTPS URL or recalled screenshot is a source locator, **not independent fact verification** or video playback.
3. Find the event's *specific editorial contradiction* before writing the line; compare competing viewpoints, humor mechanisms and narrative voices. Reject a news-only post and a literal plot recap.
4. Produce platform-native candidate headlines, copy and covers. Seven platform variants are not seven synonym/emoji replacements. X, TikTok, YouTube, Xiaohongshu, WeChat Channels, Bilibili and Douyin are the covered candidate interfaces.
5. Independently review the exact version of every candidate against two counterfactuals: substitute unrelated news and then substitute unrelated visuals. Both substitutions must destroy an essential layer of meaning. Require natural spoken language, no plotted-action retelling, and clear fictional/factual distinction. A model simulation does not count as independent human review.
6. Bind Episode/EditorialPlan and master timeline identities; verify real media rights and format; handle platform-required AI/synthetic-content disclosure at upload. Do not force generic "AI Parody" into each public headline; still honor platform policies.
7. Existing Video MediaGraph, promotion, PlatformVariant and release gates remain authoritative. Only actual release and platform analytics provide audience outcomes; revisit editorial judgment and assumptions from observed failures.

## Repair logic and counterexamples

Bad: a headline that explains the news but would pair with a generic stock chart. Bad: a funny gunfight summary applicable to any celebrity. Bad: seven copy versions with the same premise and only changed pronouns. Bad: unsupported criminal accusation disguised as satire. Bad: equating a green lint test with "human quality PASS."

The replacement should create actual news-video mutual meaning, a traceable source boundary, genuinely different candidate observations, human cold-reading evidence and new independent evaluation after material revisions. If it fails, reopen the chosen editorial angle and reasoning method, rather than only swapping a word.

Rollback can remove this non-authoritative audit interface and case without mutating CAOS, IPOS, MediaGraph, accepted video, user account or release state.

## Platform-native field contract v1.1

Public text lives in each platform_copies[].public_fields rather than an invented universal title/body pair. X uses post_text, TikTok and Douyin use caption; YouTube uses title + description (with explicit STANDARD_VIDEO format here, not unverified Shorts), Xiaohongshu title + note, Channels short_title + description, and Bilibili title + description (plus optional tags). Cover text and tag edits belong in the exact copy fingerprint, so any material publication edit invalidates its previous independent review receipt. Legacy v1.0 remains readable for historical recovery but warns against blind posting.

Each platform separately requires a PlatformVariant version, editorial format review receipt, and when media is synthetic, its actual upload-disclosure receipt. A general source video tag or a generic label in the title cannot replace platform-native disclosure. There is no automatic aspect-ratio transformation, Shorts classification, platform API call or publication here; all physical delivery remains gated by existing production/release authority.
