# 《第七次没开火》｜Agent × 战争｜原创短片导演剧本 V4

## 给观众的不是一句教训，而是一种新的可能

**核心表达**：当敌对双方都交给 Agent 自主学习战术，战争未必只会越来越快。它们也可能在交锋中发现：**有时，最有效的下一步是先不做。** 这不是一纸和平命令，更不是机器人突然有了人类感情。两个 Agent 出于各自的防护目标，独立地学习如何不触发对方的反击；短暂的克制给了一个真实的人行动机会。

**观众情绪曲线**：在机器高速反制中窒息 → 从一次反常的安静里察觉机会 → 担心谁先打破沉默 → 人物冒险 → 理解原来“不出手”也是一次自主决定。

**故事要证明的 Agent 性质**：两个 Agent 在无人逐项指挥的情况下根据实际损失更新战术，用**对手的物理行动而非谈判文字**建立条件性信任，并在新情况出现时主动调整。不能把高潮换成两名人类军官电台协商；没有任何人宣布停火，也没有交换阵地。

## 人物与物理空间（一个地点）
- **米粒（15岁）**：在战线东侧旧钟楼里；想把街心被压在倒塌自行车旁的弟弟带回来。她最害怕自己一动就让枪重新响起；但也不愿只看着他躺着。她会亲自试探、判断并冲出去。
- **弟弟小石（7岁）**：街心倒下的自行车压住裤腿，伤不致命却挣脱不了；他拿着只有一只的红色手套，另一只在姐姐手上。寒风把街上的灰吹进他的眼里。
- **左侧红灯 Agent「燧」**：获得一份简单有效的任务：“守住巷口，让己方救护车带伤员离开，尽量减少本方伤亡。”它调度三架红灯自主哨戒机，根据对手战术与己方损失修改路线、时机和开火判断。
- **右侧蓝灯 Agent「霜」**：收到“夺下巷口，护住己方补给车，减少本方伤亡”的委托，调度三架蓝灯哨戒机。它没有得到“与燧谈判”的人类指令。
- **可拍的规则**：一条只有约八米宽的街道，两侧是瓦砾；一边停着红方载有医护人员的救护车，另一边蓝方补给车里有两名士兵。无人机火力一旦射击，对方几乎立刻反击，双方侧面的人都在流弹危险范围。所有主要机位可以把**红方车 / 路中央孩子 / 蓝方车 / 双方无人机**留在同一可理解的空间里。无人机可以选择不开火，但不能自动把对方枪关掉。背景远处仍在战争，没有全线停火。

## 完整叙事时间轴（导演初稿）

### 00:00–00:10｜左右都是枪
清晨。一条窄街，两边分别是红灯救护车和蓝灯补给车。两架机群悬在街心上空，对着彼此。地上一个男孩的自行车压住了腿。东侧窗口的姐姐米粒举起另一只红手套拼命挥动。两个孩子隔街对视，但任何人伸出身体，子弹都会擦过墙沿。
**声音伏笔**：两侧枪响一前一后，像谁在复述谁。之后的战术交锋以六组清晰、可辨的「左响—右响」声效建立重复规律；第七组必须被突然到来的静默取代，否则片名与高潮失去因果。

### 00:10–00:20｜命令给出，然后人不能再跟上
红方指挥官按在通讯设备上：“车先出去。守住口子。”蓝方指挥官：“拿下这条路，不要再掉人。”一面红色视窗与一面蓝色视窗各亮一次。
未等第二句指令，红灯三机自主布成保护救护车的角形；蓝灯三机已经向侧墙伸出侦察镜头、找出红车的开口。
**画面信息**：两个 Agent 不需要人教它们下一步怎么摆位。

### 00:20–00:31｜互相学习的火力
燧指挥一机假装撤离，引出蓝方第一枪；另一红机立刻沿枪声逼近。霜不再瞄那架诱饵，而是把一架蓝机移到高墙背后向下照射红机的尾部。红机中弹坠地；蓝机紧接着也被红方另一机击落。
**动作**：一个选择触发下一个真实反应，双方都损失了一架，反制没有使战斗变安全。

### 00:31–00:42｜钟楼上的问题
炮火扬起砖灰。米粒看见小石举不动腿，街口烟尘让他咳嗽。她把手套从窗外扔下去，手套被风吹偏，落到街心，离小石只有一米。他向手套伸手；红蓝两方无人机同时跟踪这点运动，瞄准光点擦过手套。
米粒缩回来；她意识到自己可能把他害死了。

### 00:42–00:53｜第六次
两架残存红机与两架蓝机重新锁定。先前每一次开火都造成对方报复；燧把护卫救护车的机群往后缩半米，**取消一个已经对准敌机的射击动作**。蓝方瞄准镜里突然没有红方的枪口闪光。
霜继续跟踪，**没有抢先射击**；它让补给车也贴墙缩回，减小暴露。
**重点**：不是停火命令，是双方各自得到“少开一枪，本方少挨一枪”的新事实。

### 00:53–01:04｜第七次没开火
音乐第一次完全消失。钟楼外的风声、手套在路面摩擦的沙沙声清晰可闻。红灯无人机的枪口从蓝色机器胸前移开；蓝灯枪口也偏离红方救护车。两个 Agent 没有交谈，没有发出白旗，更没有离开自己守护的位置。
米粒俯身，听见一种在刚才的十几次交锋里从未出现过的声音：**什么都没有**。

### 01:04–01:16｜人的决定
米粒拿起一只铁罐，轻轻推到街上。罐子滚过两边枪口之间的白线。所有传感器随着它转动，枪却没响。
她不知道这种安静能持续多久。她看着对面的弟弟，咬紧牙，从窗边的外梯爬下来，冲向街心。
**不是 Agent 命令她走；她主动利用了它们改变出来的机会。**

### 01:16–01:29｜难题再次变化
蓝机此时正好能够击中一台暴露的红方无人机，机会比先前更好；红机也锁住了蓝方补给车一处没有遮挡的车轮。**两边都可以先得一个便宜。**
但米粒正跪在白线附近，拼命搬开压着小石的自行车。两边各自预判到：谁此刻打出第一枪，对方就会反击，己方的救护车或补给车将重新落入交叉火线。燧继续保持低枪口；霜也延长自己的不开火窗口。它们没有交换任何承诺。
**关键角色行为**：在最容易抢到战术优势的一瞬间，各自选择了维持局部静默，因为原来的策略会伤及己方。

### 01:29–01:43｜十多步路
米粒拉起小石，把他的手搭到自己肩上。两人一步一步穿过白线。她不敢看任何一支枪。离掩体两步时，小石的红手套掉在路中；米粒本能地想回头，弟弟握住她的手。她没有回头去捡。
两人穿进钟楼的门洞，跌坐在墙内。她用仅剩的那只红手套捂住弟弟颤抖的手。
**真代价**：她留在街上的不是装备或胜利旗，而是两个人曾经配对的手套；她选了人，不去找物。

### 01:43–01:50｜它们没有签停战协议
远处炮声仍在，街心的红蓝 Agent 仍互相监视。红方救护车趁静默缓缓离开，蓝方补给车仍在墙后等待，没有人得到整个街口。路中的另一只红手套在风里翻了个面。
两个 Agent 的指示灯各亮一下，枪口仍没有抬起。

**片尾图像**：空街的中央只有一只红手套，左右两边是保持警惕却暂不发火的机器。黑场。片名《第七次没开火》。

## 原始要求及不同候选的取舍
- **A《零伤亡》**：两方 Agent 用无人武器争夺战果、双方军人“零损失”、民居却全毁。主题讽刺尖锐，但剧中 Agent 缺乏变化和主动选择，容易沦为只会讲道理的反AI短片——不采用。
- **B《两次胜利》**：守方让出街口换担架停火，敌方占口。已有 V3 完整文本，但互换双方军官仍能完成同一交易，不能掩盖其结构反例——淘汰为现役导演方案，保留历史。
- **C《第七次没开火》**：敌对 Agent 不通信，靠对手物理动作与真实己方损失自主学出局部沉默；人类角色识别短暂机会并自行冒险。**优先试写**，因为物理化的“枪口不动”可见，且不是普通人类协商；仍需让独立故事编辑攻击其动机与观众理解。

## 在审稿前最危险的三个问题
1. **为什么双方 Agent 不趁对方不开枪时先打？** 剧本给的是“打响将触发即时反击并危及己方护送的真实人”。这必须通过开场实际互损、同一街道的人员空间和高潮最便宜射击机会被拒绝来证明；否则沉默没有价格，整片不成立。
2. **在没有通信的情况下，各自如何知道对方暂时不开火？** 通过上一回合枪口运动、枪口闪光缺失、机群收缩及对方反应反复更新信念；没有永久停火保证，也没有推定对方获得人类道德。
3. **是否只是自动化的条件触发器？** 要让观众看到燧设诱饵失败后调整开火策略、霜独立试探后选择减少暴露、高潮出现新可攻击机会仍主动延长静默；如果只有某个预写安全规则让机器人不射击，Agent 主体性失败。
