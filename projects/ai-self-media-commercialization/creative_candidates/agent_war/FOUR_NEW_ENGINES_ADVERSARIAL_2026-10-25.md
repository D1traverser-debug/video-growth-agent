# L03｜回到 Agent×战争的四个剧情发动机：先找不同生活，再比较谁真的有戏

**2026-10-25；研究性创作假设，不是“V7/定稿”，不进视频。** 从独立来源研究 `skills/video-growth-agent/references/storycraft-research-2026-10-25/LESSON03_AGENT_WAR_GROUNDED_SOURCE_TRANSFER_2026-10-25.md` 回到用户原始任务。过去L01/L02练会了人物在物件与专业制度里采取真实行动，下一步需要能在两分钟里让观众关心、感到意外或发现不同意义的**原创故事**，不是Agent产品演示。其他方向不因为故事有哲学词汇就降低反证标准。

## A《九点整》：同一个可靠习惯，被三种人用来证明三件不同的事（进入一个短场试验）

**从谁的实际生活出发**：一名跑战区小镇移动邮车的女司机/邮务员。她的车不只送信，还能带食品、养老金、药物——有报道和官方运营记录支持此类工作，但故事的地区、人物、军队、智能设备全部虚构。她很在意承诺准时，镇上老人则把九点的引擎声当作恢复正常生活的钟表；若中断，一些人会错过真正急需的事情。

**Agent实际授权与闭环**：
- 民间配送Agent“途”的委托：在道路不断变化、服务窗口有限的情况下，提高老人及时拿到物资的稳定性。它通过观察交接耗时/道路状态自主选择改变派送顺序、发送居民提醒、重算到站时间。没有显式命令它“每天九点钟让全部窗户一起打开”。
- 对立军事侦察Agent“影”的委托：从有限且不确定的外部轨迹中发现可能的军事活动，**仅提出待核的怀疑和进一步核验，不被授权自行攻击平民**。它观察到同一车辆日复一日九点到、多个房屋同时打开窗户，选择把那个地点加入需要进一步查看的清单；对手的先前“最佳服务”成了它更新推断的输入。
- 女司机知道邻居真实生活，不知道敌方模型的内部标签。她并非技术道德老师；当她察觉这种过于完美的同步改变居民行为，必须选择是否继续以“九点准时”的名声维系顾客的信任。

**电影最值得试的画面**：第一镜头，整条街的窗户在九点整同时打开，似乎像军队整队；第二次从近处，窗框里不是士兵，而是等药、拿退休金、想跟邮务员聊一句话的人。两种解释都由真实行为生成，不能靠最后突然宣布“窗户其实是老人”骗观众。

**更聪明的敌手反证**：如果侦察Agent能轻易辨清邮政标志或电话验证，便应撤下怀疑；若只有远距离重复时序、缺少身份信息，继续观察而非发动火力较合理，但影片必须展示其**不确定性**，不许靠“敌AI愚蠢才有危机”。车的定位服务端如果可以被对手直接看到，就没必要神秘地跟踪影子，应该采用更完整来源交代。

**更便宜的人类反证**：路过侦察员、熟悉交通的真人同样可能怀疑规律；Agent真正改变的是**两个没有互相授权的自治系统在每一次反馈里把对方行动当新特征**，从而在短时内把“便利措施→同步习惯→可识别的规律”放大。若电影没有拍出这个过程，两台Agent仍只是普通软件换皮。

**严重创作风险**：目前尾声未必有不可逆的人物选择；若只能拍出“司机关闭精准ETA，做回普通人”，就是机械反技术广告。观众也可能觉得侦察误判是战争题材很廉价的惊吓。**只许先练核心场次，不准自动扩写成114秒导演定稿。**

## B《玻璃后面》：战争中一块受损艺术品，事实与修复不是一件事（保留研究）

**生活现实**：UNESCO真实报道艺术品从被炸毁学校抢救，涉及摄影、清洁、分类、稳定处理和修复；这里已有两个专业目标可能发生紧张，而不是预制“AI冷酷、艺术家善良”。

**代理**：文物稳定 Agent 自主选择避免继续损坏的处理方案；档案取证 Agent 自主要求保存受损状态的具体证据，以便辨认来源、受害经过、日后修复。两者可能各自正确却相互改变手头物理条件。人类修复师要决定先处理哪一块濡湿纸张；他的职业能力和失败记录应成为行动依据。

**最强反证**：在正常实践里拍照记录再进行保护往往就能解决，两个Agent未必有任何真正不可兼得的利益；为戏剧强行规定“不能拍照/只有一分钟”是作者造假。**不写影片，保留知识线索。**

## C《最后一张身份证》：隐私保护与战区服务双重代理的身份冲突（当前拒绝）

**现实依据**：ICRC人道数据保护手册提到人无法证明身份、连接服务的困难、个人数据曝光的生命风险。
**代理**：身份验证Agent自主查证，隐私Agent自主隐藏敏感联系，两者都接受委托，可能把某位流亡者的申请推入循环。人物既想拿应得福利，也不愿将躲避追踪的亲属公开。
**便宜反证**：现实人道机构早有人工见证、必要披露和替代证据制度；若故事为保持两AI僵局故意禁止这些常识操作，就是“流程笑话”，且会消费真实弱者痛苦。**REJECT IN CURRENT FORM**。

## D《不在名单里的队员》：人、地面无人车与战区的猫（当前拒绝）
**真实报道**：2025年战地地面机器人执行物资任务后在回程帮助撤离一只猫；不是AI自己“突然富有良心”，而是由人安排的任务。
**代理想象**：物资Agent从部队习惯学习到猫为士气来源，医疗/福利Agent从风险信号认定需要撤走猫；两者各自制定行动，让猫被当成两种完全不同的资源。
**严重反证**：既容易模仿真实战地动物救援事件，又容易滑向“战场猫咪可爱所以AI觉醒/双方停火”的套路。即使能拍成轻快动画，也不能在缺少新视角与真正动物自主行动时宣布原创性。**REJECT AS ACTIVE FILM**。

## 真实取舍和训练反馈
A不是已经胜出成为电影，只是在四路里唯一具备**与L01/L02有明确不同的真实人际习惯、独立双Agent观察闭环、单一可重复的视觉母题**，所以值得写一场不超过60秒的**压力测试戏**。B仍需找到真正无法“先拍照后处理”化解的物理冲突；C、D不继续扩写。每一次推进都必须主动寻找“更简单的人类/设备/专业决策”击穿假造阻力。

**开放的创作结论**：A若仍弱，宁肯保留源研究而否决它，不要强迫故事沿着“今日胜利”的结局一路长成新版本。此处场次不是付费生成时码，任何技术角色不能凭作者说明自动增加电影趣味。
