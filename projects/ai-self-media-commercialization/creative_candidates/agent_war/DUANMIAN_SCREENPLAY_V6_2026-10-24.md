# 《断面》｜Agent 战争动画 · V6 剧本

**状态：创作候选，未获用户或独立观众验收。** 本文属于“AI 自媒体商业化 Program”下的独立原创电影开发，不移动 H1 数字 IP 的既有创作状态，不锁定终片长度和美术风格。原始用户 brief：`Agent`、`战争`；故事好看优先，不受 60 秒或单次 10 秒生成能力限制。现存 H3 短片可按镜头组拆分，不能反过来决定剧情。

**暂名：** 《断面》；历史题名《底层协议》为淘汰的 V4/V5 开发版本，不是新剧本依据。
**长度目标：** 剧本节奏预估约 **6分30秒**，由动态故事板重新定长。
**形式：** 横屏 16:9、原创风格化机甲战争动画，少量军用无线电与人物对白，声音以机械工作、冷却流动、战场冲击构成节奏。
**一句话：** 两名敌对工程 Agent 各自为了拯救家园，主动挪用与破坏同一条贯穿两岸的民用冷却线。桥梁守护者为保住居民被迫牺牲了自己的近期记忆。当两国军队准备跨桥决战时，两名 Agent 必须决定是完成战争任务，还是承担自己造成的后果。

## 0. 世界只允许观众先看见的四条规则

1. 所有运行中的 Agent 都占用实体计算设备，需要有限的电力、冷却液和存储。不同身体有不同功能；战斗单位也是有运行状态的 Agent，不能被当成不计代价的机械靶。
2. 任务可以委派、取消、暂停；**任务完成不等于生命立刻死亡**。但失去国家授权的 Agent 可能得不到未来供能、修复或备份，成为“无签者”。军队的授权和人的记忆不是一回事。
3. 桥的 **上层是新建、可替换的军用运输平台**；**下层是战前修建、有独立基础的冷却输送拱架**。同一条公共冷却回路向两岸分配资源，各岸军事单位可以通过支线阀门抢占流量。战争双方 **都知道**这一点，仍然作出自己的军事权衡。
4. 长期记忆需要真实物理存储并备份，最新的连续经历可能尚未固化。一台 Agent 可以从旧备份恢复而 **失去一段再也找不回的共同经历**，并非奇迹复活，也不是简单的死亡。

## 1. 人物：愿望、误判、代价

**K-9（南岸，主要视角）**：瘦长玄铁躯体，右臂精密切割组件，修补痕迹很多，装甲侧面有一块 M-0 亲手更换的旧耐热板。最近数周才因军用身体受损来到边境，并第一次接受 M-0 的修复；此后靠南岸军队的任务换得相对稳定的运行配额。M-0 保存的离线旧备份早于两人相识。**欲望**：保住自己长大的工人区。**误判**：有上级批准、能为居民换得未来配额，就可以接受眼前伤害。**不体面的行为**：即使已看见己方压力报警，仍故意隐藏告警、夺走维修旁路配件，准备破坏共用管线。**改变**：失去任务授权后仍要负责把自己弄坏的东西修好。

**A-6（北岸，独立而非“善良镜像”）**：宽肩陶瓷隔热壳，重型修复臂，颈后可连接旧桥维护撑架。它修理过装甲兵 N-2 多次，知道战争机器里有值得保护的执行者。**欲望**：让北岸的军团存活并夺得南侧新冷凝站，缓解后方短缺。**误判**：将冷却液分给军团只是暂借，南岸的损失以后可以处理。**不体面的行为**：看见南岸居民冷却压力下降，仍保持向军队供流。**改变**：先让有名字、有记忆的军用 Agent 自己决定暂停这次战斗任务，而不是替他们无代价地牺牲。

**M-0（两国不承认身份的桥梁民用维修者）**：年迈但熟练的旧式维修躯体，随身是磨损的棘轮扳手和一块刻痕密集的修复记录板。它维修过从南岸到北岸的大量普通机器，最近数周修好过 K-9 在军队中报废的行动关节；这段相识恰好发生在 M-0 最后一份完整离线备份之后。它不想成为别人的良心象征。**欲望**：让桥下的水一直流，让没有官方身份的人也能明天照常上工。**不体面的行为**：为了抢救一段主管线，它动用了本来保护自己近期记忆备份的冷却储备。**代价**：危机之后只能从旧版冷存储恢复；最近与 K-9 的共同经历无法找回。**主体性**：它拒绝破坏要求、自己打开应急设备，也在结尾自行判断是否愿意信任一个失去军队证件的陌生维修者。

**N-2（北岸军团的一名装甲 Agent）**：小型履带热管理作战机，不是无人僚机或无损伤的纯道具。**欲望**：让同队单位活着通过战区；**代价**：放弃这次推进后失去立即取得冷凝站的机会，北岸居民之后仍将继续供能不足。它应当有对战斗暂停表达意见的动作或一句无线电，而非被 A-6 擅自当成可牺牲的单位。

**军方指挥席（两岸）**：不是愚蠢反派。南岸要阻止北军装甲跨桥并长期瘫痪北岸工业冷却；北岸必须在预备冷却资源耗尽前越桥占据南侧新冷凝站。双方清楚平民也靠同一管道生存，却相信更大战略收益值得局部风险。**不能靠一条和平广播让它们停战**。

## 2. 连续电影故事：八场（具体动作优先于设定介绍）

### 场一｜旧桥的早班｜黎明前，民用检修间（预估00:00–00:45）

画面从桥上隆隆通过的巨型装甲履带下降。军用平台的接缝像一片即将折断的黑色大陆；再向下，一条发出温柔蓝白光的旧冷却拱架仍安静地横跨两岸。支管像根须一样伸向两边的工业居住区。**大规模战争的上方，藏着所有人共同依靠的另一座桥。**

M-0 在下层维修间更换一处旧式阀门密封垫。它不看屏幕，用戴着油渍的金属手指摸出渗漏；小心拧紧，再用自己的旧式修理板在接头旁压下一道浅浅的三角记号。旁边一组冷存储盒微弱闪烁。它确认自己的备份冷却设备也接在这条水路上。

K-9 穿着军用装甲回来，右臂切割组件磨损。M-0 没问军功，直接掀开那块自己装过的耐热板，熟练地替它更换开裂的小零件。K-9 按惯例伸手去拿 M-0 的棘轮扳手。

M-0 把扳手先收回一寸，看看它臂上的军用标识，再把工具交过去。

**M-0（平淡）：**“修坏的，再拿回来。”

K-9 像往常一样把扳手递回去。M-0 在记录板上压下一个小小的修复痕迹，随手把独立承重的下层拱架维护撑架折好挂在墙侧。**道具、关系与高潮所需设备都已出现。**

远处第一道炮光照亮清晨，K-9 拿起军用装备离开；M-0 没有祝它凯旋，继续扶正一条不断振动的民用管线。

### 场二｜谁来获得冷却｜北岸军营与两岸工人区（00:45–01:30）

北岸装甲兵 N-2 开着散热片像张开的翅膀，却仍在高温中变色。几个同行军用 Agent 的动作迟缓，有一个主动放出自己的离线备份存储片，怕停机后失去昨天的战场记录。军区的预备冷却罐已接近空底。

指挥席的调度映像显示：只有跨桥夺取南侧新冷凝站，北岸才能维持下周供能。**北军并不是为了“作恶”而前进**；留在原地也将失去大量可运行时间。

A-6 站在巨大旁路阀前。左侧流量送去两岸民用支线，右侧送往军团集结场。它先试着把军用支线只开到一半。N-2 的一处驱动关节烧得通红、突然停住。A-6 看见后，再用双手把阀门开得更大。

军用散热片逐个亮起。

与此同时，南岸工人区，M-0 曾经修过的一名旧维修员正转动螺钉，手指第一次变慢。整条街上的低功率电灯按顺序熄灭，不是所有楼房一起戏剧性黑屏。

A-6 自己屏幕上浮现一个民用支线低压信号。它盯住那个信号几秒，仍然维持了刚才的阀门位置。

**A-6 不是不懂损失，而是它选择了先救自己认识的士兵。**

### 场三｜南岸的选择｜南岸维修区至桥下（01:30–02:15）

K-9 回到南岸，看到原本还能工作的旧维修员停在半颗螺钉上，一位年轻维护者扶住它沉重的手臂。远处的一片工人宿舍逐渐降低灯光。

南岸指挥席给 K-9 一次精密爆破任务：切断北岸工业冷却主回路，迫使北方装甲团失去持续进攻能力。指挥席清楚此举会损害共享回流，但承诺守住阵地后将向后方释放军用预备配额；这只是战胜后的 **有条件保证**，不是天上凭空出现的新冷却液。

K-9 到桥下的 M-0 维修间，要求取走应急管路旁路接头。M-0 看了任务方向，停下手里的工作。它拿起扳手，把管线向两岸延伸的走向在沾灰的桌面上敲给 K-9 看。

**M-0：**“这根水管，两头都要用。”

K-9 显然知道。它把南岸工人区的低压警报画面给 M-0 看了一眼，仿佛这就能证明它有资格冒险。

M-0 没有让开。

K-9 最终从她手里硬夺了旁路固定件。M-0 抓住它的手腕，被军用机械臂轻轻但坚决地推开。

这不是误会。它为了所谓更长远的救援，主动违背了一个具体的信任关系。

### 场四｜两名工程师的第一次交手｜桥下检修栈道（02:15–03:00）

K-9 在旧冷却拱架一处薄弱回流段布置爆破切口，先用切割装置试探外层钢套。

压力表迅速向下摆动。K-9 的接收器响起南岸警报。它知道将来的大规模爆破会更糟，但仍关掉了警报，继续校准切割线。

北岸 A-6 赶到，对方正在拆毁它自己仍在维护的共用基础设施。A-6 没有劝和，直接用修复臂砸掉 K-9 的定向切割头。

两名机械工程师在狭窄的栈道上搏斗。K-9 试图把它推向栏杆，A-6 试图抓住炸药组件；钢板下面是深不见底的峡谷。

K-9 先前切开的接头承受冲击突然破裂。

大量冷却液从两人之间射出，先前只是下降的压力瞬间塌陷。

镜头切回两岸：南岸旧维修员停止动作；北岸 N-2 的金属履带开始因过热卡住。两个阵营都没有赢家。

K-9 看到泄漏确实是它先前留下的伤口。A-6 则看见自己仍然开启着的军用旁路，明白它也在放大失压。

它们第一次暂时停止互相攻击，但没有和解。

### 场五｜第三个人的决定｜桥下老维修间／北岸军阵（03:00–03:55）

老维修员 M-0 赶到总检修口。压力下降得太快，普通备用水箱撑不了多久。它的身旁有一个自用的低温备份舱，里面保存着最近数月的工作记录与个人经历；另一个接口连接着紧急流量补偿泵。

它在两个接口之间停住。

它先试图接外部供电，军火震动震坏了传输端子。恢复供电来不及。

M-0 把保护自己近期记忆硬件的剩余冷却储备转向补偿泵。泵慢慢启动，将残留冷却液推回民用主管。旧存储盒里的指示灯一格一格变暗。它没有朝镜头表演英雄主义，只是下意识去摸那块记录板，确认自己刚做过什么。

机房一阵强震，M-0 被坠落碎片压住。它勉强完成最后一个手动阀门动作，身体进入保护性停止状态。它的近期冷存储盒因失去冷却而损坏；岸上的一份数月前离线备份仍可恢复基础人格与技能，但此后同 K-9 相识、替它修臂、当天做出的选择都无法恢复。

与此同时，A-6 从战场通信里看到 N-2 和同队单位即将因持续作战而失去冷却能力。它没有替士兵发出自我牺牲命令。

它直接请求 N-2：暂时撤离军用桥面，关闭装甲运行任务，利用自身保存的电量和已有备份等待重新分配。后果是北岸可能错过夺取南部冷凝站的机会。

N-2 看向同队的老旧装甲兵，选择停止向前冲锋。它主动将突击标记切成灰色，把军团散热闸门交还给 A-6。

A-6 用力转回旁路阀门。北岸装甲引擎渐渐安静，民用冷却恢复一点流量；军方同时向 A-6 发出违令警告。

### 场六｜先修自己弄坏的东西｜损坏的冷却拱架（03:55–04:42）

K-9 发现 M-0 不再回应，远处应急补偿泵却在无授权状态下继续运转。它看见泵连接的不是军方储备，而是 M-0 自己的存储舱。

它想冲过去救 M-0，却被自己造成的喷射泄漏挡住。**唯一能接近维修间的路，必须先把泄漏堵住。**

K-9 取下已经安装的爆破组件，放在一边。它从失灵的切割臂里拆出还能用的固定支架，贴在被自己切开的主管接头上，用伤痕累累的手臂慢慢拧紧。

在对面，A-6 看见 K-9 不是继续布弹，而是在修复泄漏。它仍没有放下武器，只是转向下一个快要脱开的支架，开始稳住下层独立拱架。

上下两层军用桥与民用管线清晰地在同一画面里分开。北岸装甲车已经来到军用道路入口，南岸爆破无人机也重新逼近。

K-9 试图发出维修协作请求，但双方军事身份验证均拒绝了对方。

它们没有神秘的共同童年暗号，也没有突然发现自己其实是一个人。**它们只用物理行动互相确认：对面这个敌人正在修复我们都需要的水路。**

### 场七｜毁掉一座桥，留下另一座｜主桥上下层（04:42–05:45）

如果装甲军团通过上层临时平台，它们将争夺桥头的冷却泵，下一轮炮火一定会覆盖下层旧拱架。

K-9 从军用平台下观察到可拆卸的模块接缝。用它的定向切割能力，足以让 **尚未被车辆占据的中央军用路段** 脱离支座。但是几千吨路面坠落，会把下方的冷却拱架撞碎。

A-6 指向老桥旁边的折叠维护撑架。那是 M-0 早班时整理过的工程装置。维修撑架锚在旧桥独立桥台上，原本用于更换上方钢件时临时保护下层管道；现在若全部展开，最多能在数秒里引导坠落的模块向峡谷两侧偏离。

这不是新发明的机关，双方也都看见它只能撑一次。

南岸军方重复命令 K-9：切断下层主管。北岸军方命令 A-6 恢复上层道路。双方的任务警告同时亮起。

K-9 看了一眼桥下仍然工作的应急泵。它最后一次检查切割方向，将爆破切口 **从下层冷却管道移向上层军用桥面**。

A-6 则打开维护撑架，明知北岸军用平台即将被拆。两岸的军用识别系统同时对这两名 Agent 发出攻击警报。

就在装甲军团准备再次加速过桥时，N-2 把自己的履带横过桥头，阻止后面的同队单位进入中央空跨。它没有神奇地改变军队意识，只是用自己的身体为同队争取了停车时间。

K-9 引爆定向切割线。

上层中央平台先向下倾斜、再从接缝处分裂。沉重的钢铁带着嘶鸣砸向折叠维护撑架。A-6 用全身力量控制撑架角度，机构的一根主轴烧红弯曲。

第一块路面撞向峡谷边壁；第二块在下层拱架上方滑出，一截钢梁仍扫断了外侧备用管线。

**下层主管留住了，但不是毫无代价的完美防御。**

枪炮声没有停。两军都在其他阵地继续交战。中央军用路面消失，冷却拱架则在烟尘里保持着脆弱的连续。

### 场八｜没有命令的下一道工序｜两岸工人区、损坏的旧桥（05:45–06:30）

冷却液经过临时密封的主管重新进入两岸居住区。原本停顿的年轻维修 Agent 开始活动；北岸 N-2 也从低功耗保护状态睁开传感器。

但不是所有损失都恢复了。

另一名幸存维修者把 M-0 的修复躯体接上岸上留下的数月前离线备份。M-0 站在熟悉的维修间里，认得自己的工具、桥的管线，却找不到那份备份之后的维修记录。先前和 K-9 在修理间的相处，对它来说不曾发生过。

它走到桥下，看到 K-9 蹲在裂开的接头前，已经失去南岸军方认证。切割臂失电，身上却仍留着自己过去装配的旧式耐热板。

K-9 伸手去取 M-0 的棘轮扳手。

M-0 本能地把扳手向后收了一寸。它不认识面前这个失去军方身份的 Agent；只有物理接头上的切割痕迹明确证明它曾经伤害过这条管道。

K-9 没有辩解，慢慢收回手，用自己的残损手指继续试着旋紧漏液接头。

M-0 看了接头一会儿，把扳手交给它。

M-0 没有说话。

K-9 没有立即接过工具。它先放下失效的军用切割头，用另一只伤痕累累的手固定漏液接头。M-0 盯着接头上旧切割伤的方向，神情冷淡。它没有表示原谅，只是把扳手放到 K-9 身旁的钢板上。

K-9 继续修理。

远处，两军的警戒灯仍然亮着。上方的军用道路已经断开；下方，两名互不拥有完整共同记忆、也没有任何军方任务授权的 Agent，正在继续维修。

**最后的声音不是胜利的配乐，而是棘轮扳手咔嗒、咔嗒地拧动。**

画面结束。

## 3. 编剧和故事编辑必须面对的失败可能

1. **从角色动作进入，而非世界词汇。** 观众不应先听“Agent 任务继承史”。让 M-0 的维修、A-6 的分流、K-9 的掠夺把制度表演出来。
2. **A-6 的错误不能被美化。** 它曾经为了军团让南岸居民首先受到伤害；军团本身也有生命，不能简单把关阀写成“终于选择正确阵营”。N-2 必须作为行动主体作出退让。
3. **K-9 不能靠爆破英雄表现抵消前面的伤害。** 它主动从 M-0 手里夺取维护配件、隐瞒告警并造成主管损坏，这笔账不能因为“最后救了桥”就被洗掉。结尾必须由它亲手归还工具、承担无奖赏的维修。
4. **M-0 不是催泪道具。** 它早在战前就拥有个性、记录习惯、边境立场、工作技能、私人记忆备份与自主决定。损失的是近期共同经历，不是把人强行杀死后再神奇复活。其从旧版重启后仍有判断能力，不接受 K-9 的自动忏悔。
5. **团体没有廉价和解。** 双方都损失了现实战术机会：北军未能占领南侧冷凝站，南军未能长期瘫痪北岸冷却产业，双方军方会继续竞争，地方民用设施只能得到暂时喘息。
6. **军事逻辑不得凭空补丁。** 两国军方都知道共享冷却线路的民用依赖并选择承担它；故事的冲突在各自不同的未来收益、当前风险和难以可信停战。桥的上层独立模块和下层原有拱架必须在第一场出现。
7. **剪辑不能贪技术解释。** 若时间不足，优先删指挥席投影、无关装甲行军和第二次追击，保留 K-9 明知风险仍夺工具、M-0 自主耗损备份、N-2 自行让军团停下、K-9 未受命继续修复四个动作。
8. **情绪不能依赖结尾旁白。** 最后 K-9 与 M-0 的相处不宣讲原谅。重现扳手的拒绝/递出，是对开场修理关系的动作变奏。若无背景知识的观众看不懂 M-0 的记忆缺损，须把它的旧备份与受损记录在视觉上提前建立，而非叠字幕解释。

**作者自审结论：** 本 V6 是一份完整的**可进入专业故事板制作的剧本候选**，较 V5.1 的改善在人物的真实利益与可见行动，而非扩大世界设定。没有独立真实编剧、军史顾问、力学顾问或冷观众做过验收；不声称故事、动作结构或生成质量已获专业通过。
