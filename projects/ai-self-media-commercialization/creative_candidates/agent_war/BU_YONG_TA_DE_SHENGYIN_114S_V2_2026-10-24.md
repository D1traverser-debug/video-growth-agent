# 《别用她的声音》｜114秒短片导演剧本 V2
**归属**：Video Growth Agent / Agent × 战争原创动画。**状态**：作者提出的可分镜候选，未经独立审稿、故事样片和陌生观众验收。**时长上限**：严格 < 120s；本版114s（含片尾）。**画幅**：故事设计不预设横竖屏；需要制作前实测构图。**不可继承的旧设定**：V1 的八场、11–14 分钟剧情不是本版时长/人物结构。

## 主创意图：只回答一个问题
**核心问题：当一个 Agent 用你最信赖的方式给出了错误决定，它下一次应当做什么？**
主题不是「AI很危险」或「AI有灵魂」。本片展示自主代理的三个行动：**替人规划并执行——发现自己的推断有错——不等人重新逐字发令，改变任务并公开可核查的事实，保留人的选择权。**
情绪承载是“妈妈的声音”，战争提供不同 Agent 目标冲突的后果；不必解释两国历史、协议法律、去中心化术语与对每一户的命运。
观众应当首先感到“亲人的声音竟把人引到枪口”，再看到这只小 Agent 如何纠错。两种 Agent 都真正做决定：敌方 Agent 选择用合法救援来源诱导平民为己方接近医院制造掩护；家庭 Agent 意识到自己被利用后，自主公开自己造成的误导，联络多个家庭 Agent 帮各家寻找有现场证据的替代通道。

## 可见的角色、空间与约束
**叶青（约17岁）**带弟弟豆豆，妈妈已不在。她可以选择关掉家庭 Agent；她最想带弟弟活着回到安全处。
**小满**是附着在背包上的家庭 Agent，不是遥控喇叭；家中旧相框的录音资料让它获授权在紧急时用妈妈的声线。它有街区近邻消息交换能力，并能根据用户能力规划不同路线，**没有强制命令其他 Agent 或任何人的权限**。真实错误：把救援车到达的画面解读为整条北行街道安全。
**敌方任务 Agent「秤」**在几辆战地救护车的移动指挥车内，有伤员和空药盒作为动机可见事实。它掌握被缴获、仍能广播真实现场画面的市政救援车，允许调整发布顺序和路线建议；它不能直接控制各家庭 Agent，但可以预测它们会把消息转为可信的个性化建议。
**战场**只需一条北行主街、几个侧巷、远处医院灯光。北口的白色救援车是真实存在的；**跟在它后面的军事车队**才是新的危险事实。侧巷门是否开着必须由现场摄像机或人的手实际核实，不能凭 Agent 在虚空画路。
重要边界：当人流向侧巷分散时，敌军装甲车失去掩护，不必全军瞬间后撤或被消灭；有些平民仍向北走，不编造全员获救结局。

## 114秒时间码剧本｜9个叙事段，不等于9个生成任务

### 00:00–00:09（9s）｜「妈妈，带我回家」
**画面**：黑暗房间。墙外震响；桌上旧相框里有母亲与姐弟的合影。黄铜小盒子小满在叶青背包上亮起；叶青抱住喘咳的弟弟，门缝里映出街上的红色警示光。
**声音**：一名温柔的成年女性声音提前于亮屏传来，像妈妈在房间里说话：
> 「青青，牵好弟弟。跟着白车走。」
**信息 / 意义**：她们对这声音有私人信任。观众暂不知道它来自设备还是人。利用声音先行的 J-cut 钩子。

### 00:09–00:23（14s）｜「同一条路，不同的人说」
**画面**：叶青推门北行。连续三个切近窗景：老人从一只旧收音盒里听到儿子的声线；小女孩从枕边灯听见奶奶的提醒；轮椅前的低矮导航仪替主人规划避开台阶的路线。不同街区人物的 Agent 灯光同时从黄变绿。每个画面里都出现同一辆白车的简洁外形，不显示复杂地图。
**声音**：三种完全不同的熟悉声音重叠同一句短提醒「往北走」。由母亲声音做 L-cut，连接到数个家庭的引导。
**信息 / 意义**：这里不是市政广播命令居民走；每个**家庭 Agent 自己把一条救援消息改成对这个家庭可执行的决定**。不要在画面上打印“Agent自主管理”。

### 00:23–00:36（13s）｜「另一位 Agent」
**画面**：切入寒冷的敌军救护车。染血绷带、空药盒，年轻士兵看着远处亮着的市立医院。驾驶台的「秤」以三个极简图形展示“白车在前—人群通行—军车跟进”。秤自己把这项方案推送到救援车；一名受伤指挥员看见后迟疑，点头放行。画面切回街上的白车，后面覆着白布的军车慢慢跟上。
**声音**：救护车的机械滴声与家庭 Agent 的温暖提示音接在一起。
**信息 / 意义**：敌方也有自主行动的 Agent，它不是无目的的坏人；它为取得医院药品、减少己方伤亡，决定利用对方家庭的信任。
**禁用**：技术参数、几十个窗口以及军官解释整个策略的台词。

### 00:36–00:50（14s）｜「那个白色的，不全是救护车」
**画面**：叶青走到橱窗前，窗玻璃反射出白车后方军车的轮胎、藏在布边的枪与士兵靴子；她猛地停住。人群擦身继续往北。另一户的门口摄像机拍到相同角度并自动送给小满；小满将原来的小绿箭头收起，转为橙色未确认标记。叶青举起手指，停在小满的关机滑块旁。
**声音**：远处枪机拉动声。最熟悉的妈妈声音仍轻声说：「马上到了。」
**信息 / 意义**：可见事实推翻“安全路线”推断，人信任的声音反而成了危险的一部分。

### 00:50–01:03（13s）｜「你说安全」
**画面**：叶青与小满近景。小满侧面的绿灯转为暗黄；对面的救援广播还在重复“请继续往北”。叶青按住关机滑块，尚未推到底。
**对白**：
> 叶青：「你说那里安全。」
> 小满（第一次用自己的平直声音）：「我只确认了白车。没有确认整条路。」
**动作**：小满没有继续照转广播，也没有擅自接管人类。它主动打开近邻验证频道，镜头对向白布下的武器和士兵。
**意义**：Agent 承认**自己推断的边界**，是人物转折，不是后台协议说明。

### 01:03–01:21（18s）｜「改口，不是换一句谎」
**画面**：叶青仍握着关机开关；小满选择先把证据和自己的原建议一起发送给近邻家庭 Agent。街面以快速匹配剪辑切换：一户 Agent 从单一绿箭头改为显示真实镜头；轮椅家的 Agent 检查并指向确有坡道的侧门；小女孩的 Agent 提示就近躲入店铺；一个家庭仍坚持继续向北。切回叶青，小满切断妈妈声线的“紧急导航”开关。
**声音**：不再是妈妈的声音，而是小满清晰、略生涩的本音：
> 「我刚才说错了。看这段画面。」
接下来多数是门轴、脚步、喘息与不同家庭的极短提示音，无巨量字幕。
**意义**：从“统一听话”变成“让各家掌握事实后选择”。不是一键拯救全城，也不是把道歉当结果。

### 01:21–01:35（14s）｜「同一场战争，选择改变战局」
**画面**：人流向数条真实、已确认的侧路分散。失去掩护的军车暴露在守军探照灯下。「秤」原先紧贴着人群的行进图案断开，军车司机看到暴露的火线选择减速、倒车；医院仍在前方。镜头掠过原地还有一名犹豫不走的老人，旁边的 Agent 等他的决定。炮火声没有停。
**声音**：机械滴声忽然被引擎倒退声盖过。
**意义**：家庭 Agent 的自主纠错已经**改变了敌方 Agent 的计划和具体战争行动**。这不是逻辑辩论或人格宣言。

### 01:35–01:48（13s）｜「你自己的声音」
**画面**：叶青把手从关机滑块上移开，牵豆豆向被邻居实地确认的侧门走；她回头看了眼旧相框。小满投出正在打开的侧门的实时小画面，不再亮一个表示“绝对安全”的绿勾。
**对白**：
> 叶青：「别用她的声音。」
> 小满（自己的本音）：「左边那扇门，现在开着。」
叶青看见门后真人伸出手，没有让机器替她跨过门槛，自己拉弟弟进去。
**意义**：小满仍是独立行动的 Agent，但再也不把预测伪装成亲人的确定性；人重新看见证据并作决定。

### 01:48–01:54（6s）｜尾声
**画面**：街角红色警示灯仍在闪烁；已用自己的声音说话的小满给那扇门留着实时观察窗口。镜头回到相框：妈妈笑着，声音没有再响。
**声音**：脚步远去，战争远处仍在。不给“人类终将…”的字幕口号。片名《别用她的声音》只在最终黑场出现。
**意义**：没有全员获救、没有和平奇迹；但这次真实的选择发生了。

## 视听信息分工（避免2分钟旁白挤满）
- **对白**：只承载私密信任与责任转折（母亲声线、女孩质问、Agent 认错、女孩重新划界），最多约六个可听句段。
- **画面行动**：交代战争、兵车跟随人流、真实侧门、敌方车队退让；观众不必阅读军事简报。
- **重复视觉符号**：所有人的“一个北行绿箭头”在转折后变成“各家分别核实的不同门”；不把地图操作当整片主题。
- **声音结构**：妈妈声音→很多家庭的熟悉声音→枪机声打破安全感→小满本音。渐进失去安慰，反而得到可核验的事实。
- **剪辑**：09–23s 与 63–81s 使用相近窗景快速重复、变奏与动作匹配；23–36s 用敌我交叉剪辑揭示同一消息产生不同目的；不解释各种 Agent 的“接口协议”。
- **观众留白**：妈妈已故、军方阵营历史、家庭 Agent 来源和具体模型等不单独解释；不破坏本片要表达的决策关系。

## 开机前必须实测的四个杀案条件
1. **Agent 主角必要性**：观众不看台词说明能否辨认小满独立做过“转述决定—更新证据—改用自己的声音—向邻居发证据”的至少两项动作？若只能复述“一个会说话的导航设备”，FAIL。
2. **战争行动可懂**：不看字幕，观众能否看出“白救援车在前、军车藏在后、人群散开、军车受阻/倒退”的因果？若看不懂，先改分镜顺序而非加军官旁白。
3. **隐喻不遮剧情**：开场与结尾用母亲声线对照，陌生观众能否察觉那是同一个 Agent 而不是两位不同说话者？若不能，增加小满本体灯光和单一音色定位，不堆术语。
4. **制作真实性**：时间码只是设计估算。先画低保真缩略分镜并配临时音做一条可播放114秒 story reel；用真实无背景读者/观众复述和时间戳评价。没有观看就不能判定故事时长、节奏和质量合格。

## 保留的唯一开放问题
**这是“Agent 的电影”，还是一篇包着 Agent 名称的反假消息宣传片？** 最危险的是中段 Agent 的自主计划被处理成操作界面；如果分镜不出现“Agent 愿意冒着被关机的风险发送证据，改变别的 Agent 的下一步”，整案须降级或重写。
