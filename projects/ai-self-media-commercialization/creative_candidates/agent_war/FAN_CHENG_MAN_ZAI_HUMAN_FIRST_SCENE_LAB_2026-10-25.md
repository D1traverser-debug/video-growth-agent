# 《返程满载》｜Agent × 战时邮车｜人先于机器的独立短场实验

**2026-10-25；WRITER_SCENE_LAB__NOT_APPROVED_FILM。** 在前一候选《九点整》因冲突不足而退回后，尝试**从人之间的实际交流及不协调**生成情节，最后再问 Agent 自主行为能否带来额外、不同于普通软件的意外后果。本稿不是剧本V7，不承诺好笑、深刻或可开拍。

**真实素材 vs 虚构**：乌克兰邮政/AFP工作人员报告前线移动邮车除了信件，还带食品、药物、养老金，工作人员被老人抱怨、聊天、感谢，甚至对工作产生想离开的念头：https://www.dawn.com/news/1843322/ukrainian-postwoman-risks-all-to-deliver-hope-in-ravaged-east ；乌克兰政府2025年运营报道 https://mininfra.gov.ua/news/yak-pratsiuvala-ukrposhta-u-2025-rotsi-dlia-liudei-biznesu-ta-veteraniv 。以下任何具体赠礼、角色、村落、机器人功能均系原创虚构，**不描写现实战时运输方法与风险规避技巧**。

## D1：先把 Agent 整体删掉，看普通生活是否值得拍（约37秒）

战区边缘的移动邮车。陈霞用手指将老人的养老金数两遍，报纸夹在车门把手。杜伯终于收到了拣药通知，他没有马上开口，先从内衣口袋里掏出一颗用纸裹住的熟鸡蛋，塞进她手里。

陈霞：“我出来跑车，你们还得倒贴？”

杜伯不答，掰开半个旧报纸把她最喜欢的那版菜谱折出来，再把报纸递给她。

下一家，一个老太太接过购物包，反过来把一罐自家腌菜放进邮车。陈霞张嘴还没说话，老太太就先解释：“给上头那家。他有牙，能吃。”

再下一家，一名男子把修好的锅盖递出来：“你回程路过那边，带给他。上次他就是缺个盖子。”

陈霞扭头看向原本已经少了半车货的货厢：瓶瓶罐罐、锅盖、折起的菜谱、用针别住的纸条。**她不是把货送完就走的人；她莫名其妙地变成了街坊之间的运输纽带**。她叹口气，重新拿起纸笔抄收件人，不愿让任何一样东西找不到该去的人。

**作者反证**：旧邮务员也会顺手帮忙捎礼，不需要AI，不该给全片直接贴“Agent×战争”。但人际关系里已有可见的动作和带一点不协调的生活：有人嘴硬，仍做了帮助邻居的小事；没有强迫全村哭、唱赞歌或向机器讲善良。

## D2：让自主 Agent 加入，产生新的真实因果（约60–70秒）

**车门边，一小块屏幕亮着。** 自治配送 Agent「递」按上次服务数据自主调配到站时间、跟踪未交付物资、安排收发点。它有权限提出新的便民派送服务，但**无权限强迫用户寄送或使用车辆装载超限物品**。

陈霞照旧给杜伯找零钱，接过他塞来的熟鸡蛋，苦笑着收下。屏幕显示：**本车已送完：8；返程自提：0**。

到第二户，一位妇人给她一罐辣椒，指向下一条街，说：“别给我弟。他上回给我送了三罐，全是他自己不吃的。”陈霞听出她是说反话，嘴上接着她：“那我送去让他自己留着。”

屏幕摄像头只看见有人往货厢放罐子。Agent观察两次后，自行将这些未预约转交识别为**“居民间代捎请求”**，主动询问收件地址；陈霞忙着数账，随口回答了一个熟人的名字。Agent据此预留返程时间，并给登记过的居民发送：**“回程可帮忙捎带，需本人同意，轻件优先。”**

十几秒后，街对面一个男人抱着修好的灯罩跑出来，解释“送给隔壁窗那个人，他说装不上”。陈霞接过灯罩，正要核对，却又有人举起一个小面包袋：“你上回没吃午饭，这个给你。”两件事各有目的，不能都当成同一条配送任务。

Agent学到“代捎”需求持续存在，主动改变原定回程停靠顺序，屏幕里原本逐渐清空的货厢图标又一个个亮起来。它不是被写死“机器人必须收满车”，而是在每次新交接后自主更新需要问的人和已得到同意的收件目的地。

陈霞忽然看见熟鸡蛋被机器扫描成“无人确认收件人”的特殊包裹。她毫不犹豫把蛋从扫描区域拿回来，揣进自己的上衣口袋。

屏幕问：“是否创建私人包裹配送？”

“这个我自己吃。”

屏幕把它从代捎订单里删去，没有争辩。

**下一站之前，陈霞发现自己刚刚才清出一半的货厢，又堆起了一排街坊之间的零碎生活。** 她拿起笔，在一张收件标签上写下“**不要让他们两个当面碰见**”。Agent停留一瞬，询问：“是配送限制，还是人物关系备注？”

陈霞看着那个写错了又涂掉的名字，把纸折起来：“先让我把这趟跑完。”

**止于她继续工作，没有合家欢高潮，也没有“AI懂得人情”的旁白。**

## D2的严厉审稿（作者自审；独立稿件审查未做）
- **最大的因果漏洞**：前线邮务员在战区为什么能私自开启人与人之间非正式物资代捎？现实营业/安全/保管要求复杂；本片不可以靠一句“便民授权”盖过所有责任。如果要正式开发，需要专业邮政工作人员或一手规范实证。
- **Agent不可替代性仍不足**：一位经验丰富的邮务员也会因为邻里需求新开代捎；Agent只是加快询问和登记，让互动扩张更快。它不是单纯固定脚本，但还没带来**真正迫使人物改变选择**的结果。若没有新因果突破，不能扩写成电影。
- **车厢容积、风险与运输限制**：如果礼物超量，简单拒收即可；不可以为了喜剧强行让机器装一把大椅子、危及用药装载。当前画面故意只用轻件，**没有物理爆炸式笑点**，也不宣称观众会发笑。
- **人物关系**：给弟弟辣椒、给隔壁修灯罩，都在30秒以内靠台词解释，可能导致观众信息过载。只保留其中一个“口是心非”的关系，能够让表演更具体，但那又可能削弱群体连锁。
- **战争成分**：邮车处于战区边缘，工作人员有日常压力，但尚无一个不可删的战事后果。把战区换普通农村，90%动作照样成立。不是“Agent×战争”的成熟剧本。
- **故事完整性**：最后主角只是说“跑完这趟”，观众很容易预见未来还会有更多包裹；没有强烈惊奇、情绪价值上的不可逆变化。**脚本可作为写人、真实小动作、幽默尺度的训练样本，却暂时不是有说服力的商业短片发动机。**

## 迁移到下一步的真正资产
最值得保留的不是“机器学会捎带”，而是**一个嘴上拒绝、实际又彼此照看的群体；同一物品在不同的赠予者和收件人眼中不是同一种关系**。那位女司机不是哲学解说者，她有具体工作的手和自己的疲倦。想做Agent战争短片，必须有能改变这些人的真实选择的独立Agent行为，或干脆在另一个更适合Agent的真实场景里寻找故事。不为保留喜欢的段落而无休止地堆禁令。
