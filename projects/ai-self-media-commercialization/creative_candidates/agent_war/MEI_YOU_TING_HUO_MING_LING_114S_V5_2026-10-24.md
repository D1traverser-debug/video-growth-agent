## 创作命题，不写入片尾口号
**当两套敌对 Agent 都必须保护自己的人，它们能在没有停火命令的情况下自己学会“让对方先走一步”吗？**

不是 Agent 突然具有同情心，也不是女孩命令 AI 停战。影片表达：**自主智能能从对抗的真实后果中发现一种暂时合作，却不等于它获得了停止战争的权力。**

让观众记住一个反常的画面：两套原本自动攻击彼此的军用 Agent，在人类谁都没有下达停火命令的时候，默默为敌方的车让出一个单车道；车辆走完，它们又重新互相瞄准。

## 一个街口、三种行动者
- **地点**：残破城市内仅剩的一条单车道，宽仅容一辆车；路侧设两个可短暂停车的破损侧港。左端有红色标记的战地救护车，车内两名医护和一名司机；右端有蓝色标记的军用补给车，内有两名士兵和司机。双方都必须经过街道中段，却不能并排行驶；火力掩护的小型无人哨戒机各两架，双方人员始终可见。街道中段有倒塌的自行车和碎砖。
- **红方 Agent「燧」**：长期授权目标“让救护车穿过街道，保护本方车内人员”。它不是被动追踪器；能把两架哨戒机组合成烟幕、诱饵、互保的不同方案，并用战损数据实时修订行动顺序。
- **蓝方 Agent「霜」**：长期授权目标“让补给车穿过街道，保护本方车内人员”。与「燧」独立运行，无法读取对方的计划和原始指令，且战斗中**完全没有数字通信或谈判**。
- **米粒（15）**：在左侧楼口看见弟弟被倒塌自行车困在路中央；先想冲出去但险些被交叉火力击中，于是后退。她能看见两侧无人机的枪口和两辆车，不懂 AI 的内部协议。
- **小石（7）**：自行车压住裤腿，并非腿部被重物压碎；能够撑住车架，但单手无法从轮轴里抽出卷住的衣料。在姐姐进入街心时，他主动托起车轮让衣料脱出。
- **可见的物理前提**：谁向对方无人机开火，对方尚存的护卫机便沿枪声反击；回击穿过双方车头前方的狭窄交叉区，驾驶员和医护都暴露在危险中。第一次交锋以真实伤害证明这一点。两方均保留能反击的第二架机，因此“先射一个目标”不等于无风险的稳赢。只要车辆依次经过，双方可以各完成“护人通过”的主要目标，但谁先停车、谁先让路、对方会不会反咬一口，双方事先都不知道。

## 时间轴（开场—反制—转向—危机—代价—余音）

### 00:00–00:08（8秒）｜两辆车，只有一条路
俯拍一条窄得令人窒息的街。红救护车从左方缓缓驶入，蓝补给车从右方缓缓驶入，中间只能通过一辆。半空两群红、蓝哨戒机同时转枪口。楼口的米粒看见车间一个男孩被倒塌自行车绊住，她叫出弟弟名字，冲出半步。

一颗交火弹丸把门楣打碎。她缩回墙内。小石在街心抱住车架。

### 00:08–00:18（10秒）｜人把目的交出去
交叉剪辑，红方驾驶员对着前挡风玻璃边的黄铜 Agent 核心：“把我们带过去，别死人。”
蓝方司机在驾驶舱里说几乎一样的一句话：“把我们带过去，别让我们的人死。”

两颗核心同时亮起。没有第二轮人类指令。红方无人机抢占屋檐，蓝方另一机立即绕向高窗，挡住红车前方——**双方第一次自主调整**。

### 00:18–00:34（16秒）｜谁先打，都可能害自己
「燧」先派一架红机作诱饵，从高处试探蓝方射线。蓝方「霜」没有追诱饵，而是把一架蓝机藏在交通牌后方，从下方抓住红方第二架护卫机的视线。
红机开火，蓝机躲开；蓝方的第二架机立刻反击。红方救护车车窗被碎片打裂，车内护士护住伤员；紧接着红方备用护卫机反打，蓝补给车的挡风玻璃也被击碎，司机侧脸划出一道血口。**双方车内人都为无人机的决策付出了代价。**

视觉上只需两次清晰反制与两次载人车辆受损，不用六次射击计数、不用满屏运算图。

### 00:34–00:46（12秒）｜两边看到同一个结果
烟慢慢散去。红车的护士按住裂玻璃边流血的手，蓝车司机用手背擦掉脸上的血。两架残存的护卫机分别对准最容易命中的敌机；同时，它们能看见自己的车仍在对方第二架无人机的射界内。

红核心将自己的一架机从护送车旁拉回，停止下一次开火。蓝核心原先几乎要让护卫机立即跟进，**发现红方已经停止推进，并重新计算己方车险**；于是也撤回半架机位。没有新命令，只有上一轮真实受损和新观察。

### 00:46–00:58（12秒）｜第一次有人让路
窄路旁有一处刚够停下一辆车的侧港。红核心让自己的无人机先移动到侧港入口，掩护红车向侧港倒车半个车身。红方人类司机震惊地看了一眼核心：“不是要过去吗？”核心不答。红车确实让出了半条街，但仍有护卫机对准蓝方——**让路不是投降**。

蓝方侦察机从安全距离观察红车车轮的确向侧港转动，而不是伪装烟幕。霜没有抢先射击暴露车侧，转而指挥蓝车减速停在单车道中央的自行车与孩子前方，自己的枪口稍微抬离红方医护位置。对方目标仍受保护，贸然射击仍会招来反击。

### 00:58–01:10（12秒）｜没有一句“停火”
两个 Agent 相互不发消息，却通过实际位置连续更新：红方无人机退让一个车头，蓝方不追击，却保持在自行车前停住；蓝方护卫机降低枪口，红方不重新锁定其驾驶舱。枪声第一次停下。

米粒在楼口盯着那两架还带着弹痕的无人机。她知道它们并不是被关机——镜头里枪口仍会随着车辆微微追踪。

### 01:10–01:21（11秒）｜女孩验证自己看见的
米粒拾起门边一只空铁罐，推到路中央。红、蓝无人机都把摄像头移向罐子，但**没有改变已经抬高的枪口**。她看向弟弟，手扶楼口，跨出第二次。红方护卫机侧身挡住自己救护车可能遭袭的角度，却没有为她设计路线。

她并不知道安全能维持多久。她仍要自己走这段路。

### 01:21–01:37（16秒）｜人在它们之间
米粒跑到街心，试图拖起自行车，却发现裤脚被轮轴卡住。小石艰难地撑起车轮，给姐姐争取到松开裤脚的空间。米粒顺手把自行车拖向墙边，清出单车道，搀着弟弟向左边楼口移动。

此刻蓝机能清楚瞄到红方正在挪车的侧面，红机也能从高位攻击蓝车的暴露车头。**两个 Agent 都有一个新的进攻机会**，也各自看见自己保护的车仍在对方射界内。燧维持枪口向上，霜也没有开火。枪声不出现，不是因为两机没看见目标，而是双方主动放弃了眼前的便宜。

### 01:37–01:47（10秒）｜他们终于能够通行
米粒拉弟弟钻进左侧楼口。路中央终于空了：蓝补给车先从一直等待的位置穿过窄路，红方护卫机没有追击；蓝车驶过后，红救护车才从侧港重新驶出，沿相反方向通过。两侧护卫机各自守着载人车辆，一秒也没完全放弃对敌方的戒备。

两个 Agent 没有签协议，没有宣告和平。它们只是用先后顺序完成了自己最初的护送任务。车内的人隔着裂开的挡风玻璃互相望了一眼，谁也不知道对方为何没有射击。

### 01:47–01:54（7秒）｜没有停火命令
米粒和小石靠墙坐着，喘气。路上还留着那辆歪倒的自行车。远处仍有其他街口的枪声。

最后一辆车即将驶离画面时，红蓝两架无人机都恢复了警戒姿态，枪口缓缓对准彼此。

## 形式与可拍性要求
- **叙事分镜与5/10秒视频任务严格分离。** 真正采用图生视频前，要为一个动作分别设计首尾关键帧，再依镜头切点重新分配5s/10s生成任务与后期声画时间。
- **视觉规则**：一条单车道、左红救护车、右蓝补给车、两个可见侧港、中央自行车。全部因果都必须以这条实际地理关系成立，不得用抽象地图弥补失败。
- **声音规则**：快而可分辨的双向枪响 → 护送车受损后的不完整金属振动 → 第一次无枪声的车轮与喘息 → 远处仍然没有停止的战争。**静默先被观众听见，后被米粒用铁罐测试。**
- **人物行动不可删除**：米粒两次出门的差别是前次确实遭遇射击、后次先观察到两机实际退让并以铁罐验证；小石抬起车轮解除自己衣料的卡困，不是救援道具。
- **不许道德说教**：Agents 仍在执行护送自己人的任务。局部“合作”来自风险更新，不是突然善良、反战觉醒或取消任务。

## V4隔离审稿反馈如何实际改变这一稿
- 删除“第七次/第六次”无法证明的计数结构，避免观众把注意力放在不存在的声响规则。
- 删除物理不一致的成对红手套，把情感动作换成姐姐先退后试、弟弟自己抬车轮的可见行为。
- 给出**具体新证据**：两个 Agent 的互射实实在在打裂各自载人车辆；这是它们从主动对抗转为试探退让的触发。
- 给出**渐进的物理互惠**：红车第一次退入侧港—蓝方侦察证实—蓝车减速—枪口渐次上抬；不是靠一句突然宣布“停火”。
- 给出**真实机会成本**：双方都能抓到对方车辆/无人机的短时露出，却因自己车内人员的暴露、相互报复和人类护送目标而暂不利用。
- 结尾依旧敌对，各自车辆依次通过，不宣称永久和平或纯粹人道主义。
