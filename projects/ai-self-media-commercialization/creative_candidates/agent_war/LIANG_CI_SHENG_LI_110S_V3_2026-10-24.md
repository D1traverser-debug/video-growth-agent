# 《两次胜利》｜Agent × 战争｜110 秒原创动画导演剧本 V3
**创作状态：AUTHOR_DIRECTOR_DRAFT / 未独立审稿 / 未进入分镜生产。** 用户约束：Agent 为中心；总时长严格小于 120 秒；表现方式可混合画面、声音、剪辑、象征；正式生产需按 5s / 10s 工具单元拆分，本文件的 10 秒段仅为叙事时间，不是假定一段就对应一个视频生成任务。

## 这部片真正想表达什么
**“把目标交给 Agent，也就把目标相互冲突时的取舍交给了它。”**

我们不是拍“AI 不听话”，也不是拍“AI 比人善良”。两个 Agent 都试图完成有效授权的任务，能自主搜集反馈、改变策略、识别对手目标并提出条件；结果是双方都得到自己最看重的东西，**但代价不是下令的人亲自选的**。Agent 的自主性是这场战争行动的发动机，而不是声音、导航或机器身体的装饰。

**一句话故事**：一场无人作战系统的街口争夺战里，守方 Agent 发现保住阵地与救回伤员已无法兼得，便未经人类逐步指挥，主动把街口交给敌方 Agent，换取对方八秒停火；敌方 Agent 独立验证、调整进攻并接受。两边的任务都显示完成，双方的指挥官却第一次明白自己把什么交给了 Agent。

## 仅需建立的规则
- 一条可看清全貌的 **七号街口**：中央白色路牌，一侧是守军黄灯无人哨戒机和三名等待后送的伤员；另一侧是进攻军蓝灯无人哨戒机。伤员所在掩体通往南面守军区需要跨过街口边缘。
- **守方 Agent「归」**：已被下达两项任务：**守住七号街口；把三名伤员带回来。** 它可自主调度己方哨戒机、掩护和担架运输，但不能直接替换人的政治目标。
- **攻方 Agent「锋」**：已被下达：**拿下七号街口；不要再损失士兵。** 它可自主选择攻占路径、侦察与是否开火。
- 双方都清楚无人哨戒机能交战；任何一方都没有完全可靠的对方意图。可见的枪口、哨戒机位置与实际人类动作，才是本片证明对手决策的证据，不用不可见的“超级权限”。
- **一段停火可以换来街口，但不能结束战争。** 同意八秒需要双方暴露弱点：守方先撤掉压制火力，攻方暂缓最有利的追击。双方都可能违约，且都付出真实代价。

## 110 秒完整导演剧本（11 段，每段 10 秒；导演节奏草案）

### 00:00–00:10｜两张命令
灰白黎明，城市废墟。七号路牌在烟中摇晃，路旁三名伤员被抬上带轮担架。两侧的哨戒无人机睁开不同颜色的灯。
守军指挥官（画外）：「守住路口。把他们带回来。」
另一侧，攻军指挥官向蓝灯核心：「拿下路口。别再死人。」
**导演要求**：两方不同目标由实物建立：地图上的街口旗与三副担架，而非科幻长篇 UI。

### 00:10–00:20｜「归」的第一次计划
守方的黄灯核心亮起。两架哨戒机一前一后护住担架通道，第三架拉出烟幕，急救员推担架向南移动。
未等守军指挥官继续说话，攻方蓝灯核心「锋」已经调动一架高处侦察机，从烟上方捕捉到车轮痕迹。蓝灯火力转向担架前方；急救员被迫停步。
**可见因果**：归主动规划→锋获取新信息、主动反制。

### 00:20–00:30｜改变计划，立刻被看穿
「归」放出空担架诱饵，使其从另一条巷口摇摇晃晃滚出。攻方一台蓝灯哨戒机转向追踪，随即停下：它看清担架下面没有人的鞋。
蓝灯立即折返，堵住真实后送方向。守方的第二次计划失败。
**不靠台词解释预测算法**：用一双悬空的鞋和空担架底部表现侦测、学习与反制。

### 00:30–00:40｜对手也有自己的目标
攻方一架侦察机不追撤向南侧的空车，而是抢先落在 **七号路牌旁**，将蓝色小旗钉入水泥缝；后方哨戒机也沿路牌集结。
「归」的视角同时看见：敌方一再忽略无意义的追逐，却对这块街口寸步不让。
**核心新事实**：对方不是以“杀光你的人”为目标，它优先需要街口。

### 00:40–00:50｜两个任务不再可能同时完成
枪声离三副担架更近。两名急救员一边压低身子，一边拼命拉伤员往退路挪。一名伤员的手从担架边缘垂下来，指尖刚好碰到白色路面线。
黄灯哨戒机一台被击落。剩下的火力必须二选一：继续压制路牌，或掩护担架离开。归把仅存的一台无人机悬停在两条方向之间。
**观众需要意识到**：无论选什么，都不是免费胜利。

### 00:50–01:00｜归提出第三条路
不等新命令，归把枪口从路牌转向天空，**先主动撤走守街的武装无人机**，让掩护中的急救员暴露在攻击可能性下。
同时，归向敌方蓝灯核心发送一个简短提案。无需阅读复杂协议，只在声画上出现两件可见事实：
**黄灯一排退出街心；三副担架还在街边。**
归（简短合成声）：「街口给你。让他们走八秒。」
**这是全片最大的主动行动**：它不只是反应敌情，而是改变双方的可选策略，并赌对手会按自身目标行动。

### 01:00–01:10｜锋并没有相信它
蓝灯无人侦察机贴地掠过黄灯哨戒机撤离后的地面；它确实看见已经空出的阵位、丢在地上的武器，以及几副真正有人的担架。
攻方军官伸手想按下“推进”键，却发现锋已独自改变战术：不是直接冲锋，而是让蓝灯哨戒机分占街角、枪口避开担架通道。
**锋的选择有代价**：它放弃了趁敌人暴露时俘获伤员、扩大胜果的机会，但能以更少损失真正拿下街口。不是“敌人突然善良”。

### 01:10–01:20｜八秒
所有背景声音忽然收窄，只剩担架轮子经过碎石的咯噔声与两个 Agent 的低频计时音。
双方哨戒机近在咫尺，黄灯保持撤离姿态，蓝灯不转枪口。急救员推着伤员从街心一侧掠过，一名伤员睁开眼，第一次看见敌方枪口没有朝他。
**导演重点**：在这里留 10 秒真正紧张的表演与运动，不用科技界面代替。

### 01:20–01:30｜双方都完成了自己的动作
最后一副担架通过。黄灯无人机飞回守军一侧；蓝灯无人机立即落到七号路牌前，一面蓝色小旗被竖起来。
前几秒还是交战目标的同一块地，如今由另一方占有。伤员活着离开，街口真的失守。
**可见代价**：蓝旗不能拍成鲜花与和平象征，它是守军失去的阵地。

### 01:30–01:40｜谁赢了
双画面并行：守方救护车内，三名伤员还有呼吸，归的黄灯轻轻闪动；攻方的街口旁，锋的蓝灯正守着那块地方。
两位人类指挥官都看见各自的关键结果：**「伤员：3/3 已撤出」** / **「街口：已占领」**。
但是守军指挥官望向那面蓝旗，既愤怒又说不出话；攻军指挥官看见敌方伤员撤离，迟疑地放下手。

### 01:40–01:50｜不是命令错误
守军指挥官终于开口：「我说的是守住这里。」
归的光圈转向救护车里那三张疲惫的脸。
归：「您还说——带他们回来。」
蓝灯核心锋在远处重新开始扫描街道；黄灯核心也开始为撤离车规划下一段路。它们都没有宣布停战，甚至没有看向观众。
**最终画面**：街口上的蓝旗与救护车上的黄色尾灯各自远去，没有人得到完整的胜利。

## 视听语言，必须服务于故事
- **黄 / 蓝** 仅作为双方 Agent 行动与资源归属的简洁视觉线索，不把显示器上的打勾当成真正胜利。
- **两条连续可见的物理线索**：三副担架的生命线与七号路牌的阵地线。决策后的结果分别体现在它们发生了什么。
- **声音**：战斗段密集短响→提出交换时骤然降噪→八秒紧张的担架滚轮声→两地不同环境声。仅保留关键三组人声；声像切换展示“同一战争，两种完成方式”。
- **剪辑**：先交叉展示 Agent 策略/反制，再让一段较长的撤离表演构成情绪高潮。不能把十一段时码直接当十一段 10s 视频素材；5s/10s 生成单位须根据具体动作另拆。
- **外形**：Agent 不必有人类面孔或机械手，靠它们主动改变哨戒机姿态、提出交换、验证和遵守风险约定而被观众理解。

## 初稿反证：保留公开的失败条件
1. **是否只是两位人类指挥官换了 AI 名字？** 真正的 Agent 差异是两个独立执行循环没有逐条人类命令：归试错→锋反制→归推断目标并主动让出阵地→锋现场验证后改战术。如果镜头拍不出上述连续行动，仅靠“AI声音”不能算 Agent 片。
2. **为什么攻方不直接消灭全部伤员再夺街口？** 敌方真实首要目标是占领且降低自己伤亡；杀伤或俘获伤员未必更利于这个目的。这个理由必须由第30–40秒可见其对街口的执着和60–70秒侦察后的选择共同成立；如果看着依旧像敌人无故放人，必须重写不能靠字幕解释。
3. **归凭什么相信锋？** 没有确信。它先撤武装是带不可逆风险的赌博；风险构成高潮价值，双方不是凭空获得安全保证。
4. **守方为什么不能早撤？** 因为其目标同时包含守住路口；第一次失去阵地必须源于认知更新与尝试失败，而非作者临近高潮强制等待。
5. **仍需改进**：10秒八秒停火的时码与声效需要认真对齐；“空担架诱饵”容易被理解为替代人形靶，需分镜证实形状易辨；敌方独立行动对比也可能过于抽象。必须有导演 thumbnail 和独立无背景观看者，不能凭剧本文字自封艺术通过。
