# Pilot 002 — Sample V3 Shot Repair Matrix

Status: **ACTIVE REPAIR CONTRACT**  
Stage: VISUAL_PREVIEW_PROCESS_REENTRY  
Authority: derived from Sample V2 diagnostic failures, H3 Transition V1 actual-render failure, moving benchmarks and cinematic benchmark lane.

## Core objective

The next preview must make the viewer *feel* one irreversible change:

`manual app-by-app work → operating surface breaks → delegated Agent backstage → prepared result arrives`

The sequence must be understandable with captions muted. Typography may clarify, but cannot carry the causal story.

## Global invariants

1. BEFORE / CROSSING / AFTER must be visibly distinct states.
2. Human/manual state and Agent/background state must use different camera + material grammar.
3. The crossing must be an irreversible event, not merely object travel inside one environment.
4. Cheap/deterministic previs proves composition and timing before premium generation.
5. Premium generation may repair only the layers that genuinely require cinematic material/camera synthesis.
6. H3/Seedance are not default engines; they are escalation routes for high-risk or hero seconds.
7. No result is promoted from prompt quality, model reputation or still-frame attractiveness alone. Actual motion at normal speed decides.

## Shot A — Human / manual reality

**Narrative function**  
Establish the pain state: the user still has to touch multiple apps/tools manually.

**Target duration**  
~1.8–2.5 s

**Required visible facts**
- recognizably human-scale foreground: hand, keyboard/trackpad, phone/device, desk or equivalent physical interaction;
- a clear operating surface exists;
- multiple tasks are implied through behavior, not floating labels alone;
- tactile variation: skin / glass / keycaps / paper / metal / fabric or equivalent;
- one dominant focal event.

**Camera / lens grammar**
- close or macro observational framing;
- shallow-to-moderate depth separation;
- restrained camera motion, if any;
- physical perspective must feel photographed rather than diagrammed.

**Lighting / material grammar**
- motivated practical light;
- believable reflections/contact shadows;
- no generic black-tech-room look;
- no premium SaaS glass cards.

**Cheap exploration route**
- deterministic edit using high-quality authorized still/video reference;
- image keyframe generation if needed;
- local compositing for exact UI/task cues.

**Premium escalation only if**
- hand/device realism, micro-reflection or camera parallax fails the visual floor.

**Reject if**
- reads as an illustration with labels;
- the viewer understands the shot only by reading text;
- human presence feels like stock decoration rather than the source of the problem.

---

## Shot B — Operating-surface rupture / delegation trigger

**Narrative function**  
Make the old interaction model physically stop being the dominant layer.

**Target duration**  
~1.0–1.8 s

**Required state sequence**
1. BEFORE: device/app plane is intact and dominant;
2. CROSSING: one unmistakable event breaks/reorders/transcends that plane;
3. AFTER: the camera or task enters a materially different service world.

**Causal trigger candidates**
- one spoken/delegated command causes task fragments to collapse into a single intent-object;
- screen depth opens and the task leaves the UI plane;
- physical light/refraction/occlusion begins in the human world and completes in the Agent world;
- app-specific fragments lose surface identity and become backend operations.

**Camera grammar**
- direction of travel must be explicit;
- crossing should change focal depth, scale and/or camera relationship;
- camera cannot remain essentially static while only the object moves.

**Audio contract**
- one recognizable transition cue begins before the crossing and resolves after it;
- sound and picture must identify the same event.

**Cheap exploration route**
- deterministic compositing + speed-ramp / push-in / optical distortion prototype;
- first/last still frames locked before any premium video call;
- audio cue mocked before final generation.

**Premium escalation route**
- H3 FL2VA / equivalent first-last-frame control;
- Seedance reference/keyframe control if endpoint adherence is superior in test;
- one paid attempt at a time, only after endpoint stills pass.

**Reject if**
- portal + particles + cards;
- same world before and after;
- object simply travels through a corridor;
- transition is attractive but causal meaning is unclear.

---

## Shot C — Agent / backstage world

**Narrative function**  
Show that the user no longer performs each app action; the delegated system coordinates them backstage.

**Target duration**  
~2.5–4.0 s

**Required visible facts**
- one intent/task exists as the focal object/event;
- background services respond to it causally;
- task movement visibly changes the environment or activates operations;
- there is strong foreground/midground/background hierarchy;
- the viewer can infer coordination without reading service labels.

**Camera grammar**
- more spatially liberated than Shot A;
- camera may travel with or reveal the task, but movement must expose mechanism;
- at least one scale reset from close → wide or equivalent.

**Lighting / material grammar**
- light reveals routing/activation;
- moving illumination or local state change may indicate delegation;
- surfaces must show weight, occlusion and contact;
- environment should feel architected, not like a generic sci-fi hallway.

**What H3 Transition V1 taught us**
- industrial material richness alone is insufficient;
- conveyor movement is not explanation;
- static camera + box travel is below threshold;
- backend world must be designed around the causal operation, not merely styled around it.

**Cheap exploration route**
- 3D/previs or deterministic parallax mockup;
- low-cost Wan-class video for non-hero movement tests if available and quality-eligible;
- motion-graphics only for exact service/data overlays, never as the world itself.

**Premium escalation route**
- only if cheap route proves staging but fails material/camera realism.

**Reject if**
- generic industrial conveyor;
- generic cyberpunk corridor;
- repeated modules/cards;
- mechanism is invisible without labels.

---

## Shot D — Prepared result / hero payoff

**Narrative function**  
Deliver the payoff: the delegated backstage work returns as one prepared result.

**Target duration**  
~1.8–2.8 s

**Required visible facts**
- one unmistakable finished result object/event;
- composition and scale differ materially from Shot A;
- result arrives because of the prior causal chain;
- image works without explanatory copy;
- this should be the strongest still frame of the sample.

**Camera / composition**
- decisive settle or reveal;
- enough hold for recognition;
- no frantic motion after the reveal;
- visual hierarchy must survive thumbnail-size inspection.

**Lighting / material**
- payoff lighting should complete the transition arc, not merely become brighter;
- result should feel physically present and authored;
- avoid returning to a floating card/dashboard.

**Cheap exploration route**
- lock hero still first;
- deterministic typography/data added only after the image passes without text.

**Premium escalation only if**
- hero material, camera settle or delivery interaction cannot reach benchmark through compositing/low-cost video.

**Reject if**
- removing text destroys the meaning;
- ending is merely a result card;
- final image is less memorable than the backend transit shot.

# Engine routing for V3

## Tier 0 — deterministic / effectively free
Use first for:
- subtitles;
- exact typography;
- UI/data overlays;
- timing;
- speed ramps;
- compositing;
- audio cue prototypes;
- first/last frame assembly;
- contact sheets and QA.

## Tier 1 — low-cost exploration
Eligible for:
- camera/parallax tests;
- non-hero generative movement;
- material exploration when endpoint fidelity is not critical.

Candidate class:
- Wan-class low-cost hosted routes or equivalent.

Promotion condition:
- actual artifact reaches quality floor and respects shot contract.

## Tier 2 — scarce premium generation
Eligible engines:
- MiniMax H3;
- Seedance 2 / Seedance 2 Fast;
- equivalent premium model only after measured comparison.

Use only for:
- Shot B crossing if endpoint-controlled cheap routes fail;
- Shot C high-risk cinematic material/camera layer;
- Shot D hero payoff if cheaper routes fail the image-weight threshold.

Current vidIQ H3 rule:
- **no blind exploration**;
- **no whole-film generation**;
- **one shot / one paid attempt at a time**;
- first/last states must already be approved internally before submit.

# Sample V3 acceptance test

The preview remains FAIL unless every condition below is true:

- [ ] first meaningful visual change occurs within 0.5 s;
- [ ] first 2 s establish a specific manual-work problem;
- [ ] BEFORE / CROSSING / AFTER are visibly distinct;
- [ ] human and Agent worlds use different material/camera grammar;
- [ ] transition reads correctly with captions muted;
- [ ] backend operation is causal, not decorative transit;
- [ ] at least one meaningful shot-scale reset exists;
- [ ] hero frame is poster/thumbnail-worthy without text;
- [ ] no generic SaaS / cyberpunk-template dependence;
- [ ] sound cue and picture event are synchronized semantically;
- [ ] actual rendered motion is reviewed at normal speed;
- [ ] all hard visual dimensions are >= 4/5;
- [ ] Creative Director average is >= 4.25/5;
- [ ] complete immutable blind-review receipt bundle exists for the exact artifact digest.

Until all items pass, the 59.5-second rebuild stays frozen.
