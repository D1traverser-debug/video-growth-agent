# Pilot 001 — AI automatic video production

Purpose: prove the production system can research, script, produce and audit a publishable short video with near-zero incremental cash cost.

Key durable findings from V1–V9:
- “runs successfully” is not “publishable”.
- Template/PPT/SaaS-dashboard visuals fail the brand bar even when technically clean.
- Low-quality pseudo-3D is not an upgrade merely because it has perspective.
- Real production evidence (code, failed render, stream probe, rejection/re-render) can be stronger than invented futuristic interfaces.
- Container duration can look correct while the video stream is truncated; probe streams and frame count separately.
- Final AAC encoding can change peak behavior; measure final true peak.
- A black-box editor that cannot inspect its own final render cannot own final QA.

This page stores durable production lessons, not a claim that Pilot 001 is the permanent visual template.
