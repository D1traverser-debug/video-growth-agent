# Video Growth Agent

Executable skill and production system for low-cost, high-quality short-video creation, self-critique, commercialization, and continuous workflow improvement.

**Authority model**
- GitHub `main`: executable rules, prompts, gates, orchestration, tests.
- Notion / Google Drive: research corpus, human-readable mirrors, recovery notes, benchmark knowledge.
- Project artifacts: rendered media, QA evidence, source assets, performance receipts.

The system treats video production as a virtual studio rather than one monolithic agent: strategy, research, writing, retention, directing, art direction, storyboard, motion, assets, editing, sound, technical QA, commercial fit, compliance, and red-team review each have independent responsibilities and veto conditions.

Current status: initial executable Skill baseline under construction.
